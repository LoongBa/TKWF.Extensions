# 账户管理扩展使用指南

> **扩展**: `TKWF.Ext.Account` | **版本**: V0.3.0 | **框架**: .NET 10

本指南帮助消费方集成账户管理扩展，获得**账户锁定策略**与**密码重置流程**的默认实现（主框架缺口）。

---

## 一、能力概览

| 能力 | 说明 |
|------|------|
| 账户锁定 | 连续失败达阈值自动锁定（默认 5 次 / 15 分钟），框架 AuthController 自动调用 |
| 密码重置 | 随机码生成/存储/过期（默认 30 分钟）/幂等消费，防用户枚举 |
| 主框架缺口补齐 | 实现 `IAccountLockoutPolicy` + `IPasswordResetFlow`（V4.9.45 扩展点） |
| 存储抽象 | `IAccountLockoutStore` / `IPasswordResetStore`（FreeSql 默认，可替换） |
| 登录历史与异常检测 | `ILoginHistoryService`（V0.3.0）——登录历史分页/过滤 + 失败次数 TopN（消费 SecurityLog 扩展查询 API，不重复建表） |

**边界**：登录/注册/改密 API 复用主框架 `AuthController<TUserInfo>`；密码落库由消费方 `IAccountPasswordManager` 适配（可对接 Identity 扩展）。

## 二、安装

### 2.1 引用扩展项目

```xml
<!-- 消费方 .csproj -->
<ItemGroup>
  <ProjectReference Include="..\..\_Framework\Account\TKWF.Ext.Account.csproj" />
</ItemGroup>
```

### 2.2 启用扩展（v4.9.85+ 必需）

> **V4.9.85 (ADR47) 起**：扩展不再"发现即启用"。消费方需在领域初始化器上显式声明 `[TKWFEnabledExtension]`，扩展才进入白名单（三钩子执行）。

```csharp
// 消费方领域初始化器（DomainHostInitializerBase<TUserInfo> 子类）
using TKWF.Ext.Account;

[TKWFEnabledExtension(typeof(AccountExtensionInitializer<>))]
public class MyDomainInitializer : DomainHostInitializerBase<MyUserInfo>
{
    // ...
}
```

自动注册：`IAccountLockoutStore`（`FreeSqlAccountLockoutStore`）+ `IPasswordResetStore`（`FreeSqlPasswordResetStore`）+ `IAccountLockoutPolicy`（`FreeSqlAccountLockoutPolicy`）+ `IPasswordResetFlow`（`DefaultPasswordResetFlow`）。

## 三、使用

### 3.1 密码落地适配器（密码重置必需）

扩展不提供 `IAccountPasswordManager` 默认实现——消费方实现并注册（对接 Identity 扩展的 `IUserManager`）：

```csharp
// 消费方：实现 IAccountPasswordManager
public sealed class IdentityPasswordManager : IAccountPasswordManager
{
    private readonly IUserManager _userManager; // 注入 Identity 扩展
    public IdentityPasswordManager(IUserManager userManager) => _userManager = userManager;

    public async Task<bool> UserExistsAsync(string userName, CancellationToken ct)
        => await _userManager.FindByNameAsync(userName, ct) is not null;

    public async Task<bool> SetPasswordAsync(string userName, string newClientHash, string salt, CancellationToken ct)
    {
        var user = await _userManager.FindByNameAsync(userName, ct);
        if (user is null) return false;
        await _userManager.ChangePasswordAsync(user.Id, newClientHash, ct);
        return true;
    }
}

// 消费方 ConfigureServices 中注册
services.AddScoped<IAccountPasswordManager, IdentityPasswordManager>();
```

> 不注册时：密码重置发起返回 false（Warning 日志），账户锁定仍正常工作。

### 3.2 账户锁定（框架自动调用）

注册 `IAccountLockoutPolicy` 后，主框架 `AuthController.LoginByContextAsync` 自动执行锁定检查与失败计数——**无需手动接线**。

```csharp
// 手动检查/解锁（如管理后台）
public class AdminService(IAccountLockoutPolicy lockoutPolicy)
{
    public async Task<bool> IsLockedAsync(string userName) => await lockoutPolicy.IsLockedAsync(userName);
    public async Task UnlockAsync(string userName) => await lockoutPolicy.UnlockAsync(userName);
}
```

行为：连续失败 ≥ `MaxFailedAttempts`（默认 5）→ 锁定 `DefaultLockoutMinutes`（默认 15 分钟）；登录成功自动清除计数。

### 3.3 密码重置

```csharp
// 注入 IPasswordResetFlow
public class PasswordResetService(IPasswordResetFlow resetFlow)
{
    // 发起重置（返回 true——用户不存在也返回 true 防枚举）
    public async Task<bool> InitiateAsync(string userName)
        => await resetFlow.InitiateResetAsync(userName);

    // 完成重置（客户端已计算 PBKDF2：newClientHash + salt，服务端仅存储）
    public async Task<ResetResult> CompleteAsync(string userName, string code, string clientHash, string salt)
        => await resetFlow.CompleteResetAsync(userName, code, clientHash, salt);
}
```

行为：重置码 8 位随机（去混淆字符集），有效期 `ResetCodeValidityMinutes`（默认 30 分钟）；使用后标记 `IsUsed`（幂等，重复提交无效）。

### 3.4 配置选项

```json
{
  "TKWF": {
    "Account": {
      "MaxFailedAttempts": 5,
      "DefaultLockoutMinutes": 15,
      "ResetCodeValidityMinutes": 30,
      "IsEnabled": true
    }
  }
}
```

### 3.5 登录历史与异常检测（V0.3.0）

> **前置**：须启用 SecurityLog 扩展——登录历史数据来源于 SecurityLog（**唯一数据源**，Account 不重复建表）。

**① 启用 SecurityLog 扩展**（消费方领域初始化器双白名单）：

```csharp
using TKWF.Ext.Account;
using TKWF.Ext.SecurityLog;

[TKWFEnabledExtension(typeof(AccountExtensionInitializer<>))]
[TKWFEnabledExtension(typeof(SecurityLogExtensionInitializer<>))]
public class MyDomainInitializer : DomainHostInitializerBase<MyUserInfo>
{
    // ...
}
```

SecurityLog 未启用时，调用登录历史/异常检测 API 会抛 `InvalidOperationException`（消息提示须启用 SecurityLog 扩展——C1 模式，对齐 NotificationPublisher）。

**② 查询登录历史**：

```csharp
public class SecurityDashboard(ILoginHistoryService loginHistory)
{
    // 分页查询登录历史（默认 50 条/页，上限 200；UserName/IP 模糊匹配，Result 精确匹配，时间范围 UTC 含边界）
    public async Task<LoginHistoryPagedResult> PageAsync(int page)
        => await loginHistory.GetLoginHistoryAsync(new LoginHistoryQueryInput
        {
            UserName = "alice",
            Result = "Failed",
            Skip = (page - 1) * 50,
            Take = 50
        });
}
```

返回项 `LoginHistoryItemDto`：Id / UserName / UserId? / IpAddress / UserAgent?（**列表投影恒 null**——SecurityLog 列表 DTO 不含 UA，D5 安全决策）/ Result / CreateTime（UTC）。

**③ 异常检测（暴力破解/撞库）**：

```csharp
// 最近 30 分钟失败次数 Top10 用户名（疑似撞库目标）
var topUsers = await loginHistory.GetTopFailedUsersAsync(topN: 10, window: TimeSpan.FromMinutes(30));

// 最近 30 分钟失败次数 Top10 来源 IP（疑似扫描/爆破源）
var topIps = await loginHistory.GetTopFailedIpsAsync(topN: 10, window: TimeSpan.FromMinutes(30));
```

`LoginFailureStat`：Dimension（用户名 / 来源 IP）+ Count（窗口内失败次数；仅计 `Result=="Failed"` 记录，空白维度跳过）。

**边界**：登录历史列表不含 Detail 详情全文（异常消息不进列表）；完整详情（含 UA/Detail/CorrelationId）经 SecurityLog 扩展 `ISecurityLogQueryService.GetDetailAsync(id)` 获取。

## 四、实体表结构

| 表 | 说明 | 关键列 |
|----|------|--------|
| `AccountLockout` | 账户锁定记录 | UserName / FailedCount / LockoutEnd（DATETIME? 本地语义）/ LastFailedTime |
| `PasswordResetCode` | 重置码记录 | UserName / ResetCode / ExpireTime（DATETIME 本地语义）/ IsUsed |

两表经 SG1 + `FreeSqlTableStructureSynchronizer` 自动建表。

> **注**：FreeSql SQLite 对 `DateTimeOffset` 写入不可靠（读回丢失），Account 业务时间字段统一采用 `DateTime`（本地时间语义）；审计时间（CreateTime/UpdateTime）保留 `DateTimeOffset`。

---

## 五、安全语义

- **防用户枚举**：`InitiateResetAsync` 用户不存在也返回 true
- **幂等消费**：重置码使用后标记 `IsUsed`；重复提交返回失败
- **过期失效**：重置码超期自动失效
- **锁定回退**：锁定检查异常时静默返回"未锁定"（不阻塞登录）
- **TryAdd 语义**：消费方自定义存储/策略优先
- **系统保护**：登录成功自动清除失败计数

## 六、常见问题

**Q: 账户锁定能自定义阈值/时长吗？**
A: 可以，配置 `TKWF:Account:MaxFailedAttempts` / `DefaultLockoutMinutes`；或实现自定义 `IAccountLockoutPolicy` 替换（TryAdd 语义）。

**Q: 密码重置如何发送验证码给用户？**
A: V0.1.0 不内置通知渠道。消费方在调用 `InitiateResetAsync` 后自行获取/通知（可对接 Emailing 扩展发送邮件）——重置码在调用方可见范围内。V0.2.0 计划提供通知回调。

**Q: 忘记密码后的新密码怎么算？**
A: 主框架 SecurePassword 契约：**客户端**计算 PBKDF2 得到 `newClientHash` + `salt`，服务端仅存储不落明文——`CompleteResetAsync` 的 `newClientHash`/`salt` 参数即此语义。

**Q: 需要管理员解锁用户吗？**
A: 注入 `IAccountLockoutPolicy` 调用 `UnlockAsync(userName)` 即可（见 §3.2）。
