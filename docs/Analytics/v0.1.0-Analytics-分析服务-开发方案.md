## 一、需求分析

### 1.1 背景

DMP-Lite 已有 6 个分析型 VEntity（销售趋势/支付分布/门店排行/品类分布/会员增长/会员来源），消费侧 AdminUI/AdminWeb 各自手写图表——**数据形态与可视化强绑定**：每个分析意图对应单一图表类型，新增图表需重写 VEntity 或 Service；运行期不可切换（D20 §1.2）。

D20 设计（v1.1）确立 AnalysisSpec 产物规范（semantic_types + chart_spec + manifest，git-tracked `docs/analytics-specs/`）+ flint-chart 渲染（单一真相归 flint schema）——但落地前缺**框架级标准读取/校验路径**。

### 1.2 消费需求

- **spec 读取**：消费方按 specKey 读取 semantic_types/chart_spec/manifest（JSON 原样透传）
- **状态校验**：manifest.status（stale → 强制重生；deprecated → 放行标记）
- **统一 API**：AdminUI (Blazor) 与 AdminWeb (React) 经统一服务获取 spec（`[GenerateController]` 暴露）

### 1.3 目标

两层架构落地（对齐 Metrics 完整先例）：核心加载校验进主框架 `TKW.Framework.Utility.Analytics`（零依赖，可脱离扩展独立使用）；集成门面 `IAnalyticsQueryService` + Options + Initializer 进本包 `TKWF.Ext.Analytics`（消费方引一包 + 白名单声明即得完整分析能力）。

### 1.4 非目标

- ❌ 不做 ChartAssemblyInput 组装（前端直调 flint `assemble()`，D20B §5.1 P1）
- ❌ 不查业务数据（tkwf-service 职责；DataShapeMismatchException 仅定义不抛出）
- ❌ 不做 chartType ∉ flint 注册表校验（前端 flint assemble 职责，核心不硬编码模板名）
- ❌ 不做服务端像素渲染（返回 spec/Excel artifact，D20B §4.5）
- ❌ 不做 spec 自动重生 build 钩子（tkwf-analytics-view skill 完整 AI 意图分解，D20 §9.1）

| `TKW.Framework.Utility.Analytics`（主框架 Utility/Analytics/ 子目录，进 TKWF.Utility 程序集） | 核心（零依赖） | `AnalyticsSpecLoader`（加载+JSON 解析）+ `AnalyticsSpecValidator`（manifest 状态校验）+ `AnalyticsSpecOptions`（POCO）+ 3 异常（SpecStale/ChartSpecLoad/DataShapeMismatch）+ `AnalyticsSpecConstants`（目录约定 + 路径安全正则 + flint 版本） |
| `TKWF.Ext.Analytics`（扩展仓库 _Framework/Analytics/） | 集成层 | `IAnalyticsQueryService`（门面 4 方法）+ `AnalyticsQueryService` + `AnalyticsOptions`（`[Options("TKWF:Analytics")]` 派生 POCO）+ `AnalyticsExtensionInitializer<TUserInfo>`（三钩子） |
| `Extension.Analytics.Tests`（扩展仓库 _Tests/） | 测试 | 门面组合 Loader/Validator、pivot-hint、manifest 透传、stale 语义、DI 接线（11 用例） |

### 接口设计（D20 §5.3 落地，P0-2 domain 显式参数）

```csharp
namespace TKWF.Ext.Analytics;

public interface IAnalyticsQueryService
{
    Task<JsonDocument> GetSemanticTypesAsync(string domain, string specKey, CancellationToken ct = default);
    Task<JsonDocument> GetChartSpecAsync(string domain, string specKey, string? chartType, CancellationToken ct = default);
    Task<IReadOnlyList<string>> ListPivotChartTypesAsync(string domain, string specKey, CancellationToken ct = default);
    Task<JsonDocument> GetManifestAsync(string domain, string specKey, CancellationToken ct = default);
}
```

- `JsonDocument` 透传（不镜像强类型——flint 单一真相 D20B §4.3）
- `domain` + `specKey` 双参（目录 `{specRoot}/{domain}/{specKey}/`；specKey = `{VEntityName}--{intent}`）
- `GetManifestAsync` **不校验 status**（manifest 是状态展示载体，P1-4）
- `ListPivotChartTypesAsync` 读 pivot-hint.json allowedTransitions（可选文件缺失 → 空列表；实际切换由 flint 前端门控，P1-3）

### 核心校验规则（Oracle P0-3/P1-5）

```
GetSemanticTypesAsync / GetChartSpecAsync:
  1. domain/specKey 命名校验（正则，失败 → ChartSpecLoadException）→ 路径拼接
  2. 读 manifest.json → status 校验（stale → SpecStaleException；缺失 → 视为 stale）
  3. 读目标文件（缺失/JSON 损坏 → ChartSpecLoadException）
  4. [仅 GetChartSpecAsync] chartType 文件不存在 → fallback primaryChartSpecFile
GetManifestAsync:
  1. 命名校验 → 路径拼接 → 读 manifest.json（不校验 status）
```

## 三、关键设计

### 3.1 分层（用户裁定 2026-09-16，对齐 Metrics 完整先例）

| 维度 | 核心层 `Utility.Analytics` | 集成层 `TKWF.Ext.Analytics` |
|------|---------------------------|------------------------------|
| 定位 | 零依赖纯 C#（文件 IO + JSON 校验） | DI/Options/API 接线 |
| IOptions | ❌（`AnalyticsSpecOptions` 纯 POCO，P0-1） | ✅（`AnalyticsOptions` 派生，`[Options]` 绑定合法） |
| 异常 | 定义全部 3 类（结构化属性 SpecKey/ChartType/Reason） | DataShapeMismatch **仅引用不抛出**（P0-4） |
| 实例 | `AnalyticsSpecLoader`（构造传 specRoot/POCO） | `AnalyticsQueryService`（注入 Loader，Singleton 无状态） |

### 3.2 双模式引用（2026-09-16 方案 B，扩展仓库 AGENTS.md §6）

| 模式 | 开关 | 引用方式 | 用途 |
|------|------|---------|------|
| 本地联调 | `UseLocalFw=true`（默认） | **DLL 模式**：`$(TKWFDeployPath)\build\refs\` 预编译框架 DLL | 本地开发（对齐消费项目；替代早期 ProjectReference 跨仓库耦合） |
| NuGet 发布 | `UseLocalFw=false` | PackageReference（CPM：TKWF.Domain/TKWF.Utility 4.10.27+） | CI/发布，验证真实消费方视角 |

### 3.3 路径安全（Oracle P0-3 + 审查加固）

- `domain: ^[a-z][a-z0-9-]*$`、`specKey: ^[A-Z][a-zA-Z0-9]*--[a-z][a-z0-9-]*$`（`AnalyticsSpecConstants` 强制校验）
- chartType 文件名消毒（`IsValidChartTypeFileName` 仅字母数字连字符，防 `../` 注入）——审查追加
