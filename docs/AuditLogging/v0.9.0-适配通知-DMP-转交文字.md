【TKWF 扩展模块组 · 审计扩展适配通知】

各位好，审计相关扩展已发布以下版本（tag 已推、本地部署已同步）：

- TKWF.Ext.AuditLogging              v0.9.0  （主包；已移除 AspNetCore 框架引用）
- TKWF.Ext.AuditLogging.Abstractions v0.2.2
- TKWF.Ext.AuditLogging.Web          v0.1.0  （新增：业务审计 Web 端点，opt-in）
- TKWF.Ext.SecurityLog               v0.5.2  （+ TenantId 列）

【需要你们做的】
1. **生产库加列（必做）**：执行附件 SQL（3 列，均可空）——
   `TKWF_AuditLog.TenantId`、`TKWF_SecurityLog.TenantId`、`TKWF_BusinessAudit.AttributesJson`。
2. 若引用了 `AuditImmutabilityOptions`：删除（类型已移除）。
3. 若自定义实现 `IBusinessAuditWriter` / `IAuditAccessPolicy`：按通知 §三.3 / §三.4 适配。
4. 业务审计查询调用方：拒绝语义改为抛 `AuditAccessDeniedException`，请处理（§三.5）。
5. 若已用 v0.8 in-package Web 端点：迁移到 `TKWF.Ext.AuditLogging.Web`（§三.6）。
6. 后台作业导出/特权删除：需 `AllowWithoutPermissions=true` 或自定义策略（§四）。

【零改动】
仅用 `IAuditLogStore` 写入 + 既有查询的，除 DDL 外无需改代码。
