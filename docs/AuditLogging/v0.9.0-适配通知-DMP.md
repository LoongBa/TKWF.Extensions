## 三、必改项

### 1. 生产 DDL（加列，可空）

```sql
-- PostgreSQL
ALTER TABLE "TKWF_AuditLog"      ADD COLUMN "TenantId"      BIGINT NULL;
ALTER TABLE "TKWF_SecurityLog"   ADD COLUMN "TenantId"      BIGINT NULL;
ALTER TABLE "TKWF_BusinessAudit" ADD COLUMN "AttributesJson" TEXT   NULL;

-- SQL Server
ALTER TABLE [TKWF_AuditLog]      ADD [TenantId]      BIGINT        NULL;
ALTER TABLE [TKWF_SecurityLog]   ADD [TenantId]      BIGINT        NULL;
ALTER TABLE [TKWF_BusinessAudit] ADD [AttributesJson] NVARCHAR(MAX) NULL;

-- SQLite
ALTER TABLE TKWF_AuditLog      ADD COLUMN TenantId      BIGINT NULL;
ALTER TABLE TKWF_SecurityLog   ADD COLUMN TenantId      BIGINT NULL;
ALTER TABLE TKWF_BusinessAudit ADD COLUMN AttributesJson TEXT   NULL;
```

> **可执行脚本（含校验查询，交 DBA）**：`docs/AuditLogging/v0.9.0-DDL-生产加列.sql`
> 开发环境 `UseAutoSyncStructure=true` 自动加列；存量行为 `NULL`，租户过滤仅在传入 `TenantId` 时生效。

### 2. `AuditImmutabilityOptions` 删除（C3）

- 代码 `services.Configure<AuditImmutabilityOptions>(...)` → 删除（类型不存在，编译失败）。
- 配置 `TKWF:AuditLogging:AllowPrivilegedDelete` → 可保留（不再读取）或删除。
- 特权删除改为能力注册：`services.AddAuditPrivilegedDelete()`（§五）。

### 3. `IBusinessAuditWriter` 新增 `SaveStrictAsync`（自定义实现必补）

```csharp
Task SaveStrictAsync(BusinessAuditEntry entry, CancellationToken ct = default);
```
语义：写失败**必定抛出**（不受 `FailOpen` 影响），供特权删除"留痕失败即中止"。仅用默认实现者零改动。

### 4. `IAuditAccessPolicy` 升级为领域服务（自定义实现必改）

1. 继承 `DomainServiceBase`，ctor 增加 `IDomainUser user` 并 `: base(user)`；
2. 注册 `services.AddConstructibleService<IAuditAccessPolicy, 你的实现>()`；
3. 解析 `User.Use<IAuditAccessPolicy>()`（不再 `GetService`）。
用默认 fail-closed 策略者零改动。

### 5. 业务审计查询"拒绝"改为抛异常（C2）

`IBusinessAuditQueryService.GetListAsync / CountAsync / GetDetailAsync / GetDetailWithPayloadAsync` 拒绝时抛 `AuditAccessDeniedException`（`ErrorCode = "AUDIT_ACCESS_DENIED"`），不再返回空/null。
- 调用方 `try/catch (AuditAccessDeniedException)`；或保证放行（`AllowWithoutPermissions=true` 或自定义策略）。

### 6. Web 端点迁移（若已用 v0.8.x in-package Web）

业务审计 Web 端点已移出主包，改由 `TKWF.Ext.AuditLogging.Web` 承载；主包不再引用 AspNetCore。
1. 引用 `TKWF.Ext.AuditLogging.Web`；
2. `[TKWFEnabledExtension(typeof(AuditLoggingWebExtensionInitializer<>))]`；
3. `UseWebExtensions(e => e.Add<TKWF.Ext.AuditLogging.Web.AuditLoggingWebExtension>())`；
4. 移除对主包 `AuditLoggingWebExtension` 的引用。
未用 Web 端点 → 零改动（且不再被动引用 AspNetCore）。

### 7. 配置绑定需 `IConfiguration`（条件）

新增/生效配置键（宿主须注册 `IConfiguration`，非 Web 宿主未注册时审计组件解析失败）：
- `TKWF:AuditLogging:FailurePolicy:FailOpen`
- `TKWF:AuditLogging:EventPublishing:PublishEvents`
- `TKWF:AuditLogging:AccessPolicy:AllowWithoutPermissions`
- `TKWF:AuditLogging:Export:MaxRows`（默认 10000，超限抛 `AuditExportLimitExceededException`）

## 四、行为变更（需验证，尤其后台作业）

1. **敏感操作（QueryAll/Detail/Export/Delete/Purge）**：需"已认证 **或** 系统帧"，且 `AllowWithoutPermissions=true`（默认 false → 拒绝）。后台作业导出/特权删除须显式开启或自定义策略。
2. **导出默认拒绝**：`IAuditExportService` 需 `AuditOperation.Export` 放行；单次上限 `MaxRows`（默认 10000）。
3. **统一读门面策略门控**：`IAuditQueryService` 的 Query/Count/Correlation/Incremental 需 `QueryAll`，详情需 `Detail`。
4. **系统帧**：`IsSystemActor=true` 视为"已认证"（仍需 `AllowWithoutPermissions`）。

## 五、可选增强（非必改）

| 能力 | 用法 |
|---|---|
| 统一读模型 | `User.Use<IAuditQueryService>()`（`QueryAsync`/`GetDetailAsync`/`CountAsync`/`GetByCorrelationAsync`/`GetIncrementalAsync`；缺面抛 `AuditFacetUnavailableException`） |
| 导出（G6） | `User.Use<IAuditExportService>().ExportAsync(facet, query, AuditExportFormat.Csv\|JsonLines, stream)` |
| 完整性 | `IAuditIntegrityProvider.ComputeHashAsync / VerifyAsync`（默认 SHA-256，可 Replace） |
| 水位（G8） | `IAuditWatermarkStore.GetAsync / SetAsync`（默认内存，生产建议 Replace 持久化） |
| 受控详情 | `IBusinessAuditQueryService.GetDetailWithPayloadAsync(id)` → `BusinessAuditDetailDto`（含 Before/After/AttributesJson，`Detail` 门控） |
| 业务审计扩展 | `BusinessAuditEntry.Attributes`（脱敏落 `AttributesJson`）；`BusinessAuditQueryInput.AfterId`（keyset） |
| 特权删除（C4） | `services.AddAuditPrivilegedDelete()` → `User.Use<IAuditPrivilegedDeleteService>().DeleteAsync(facet, id, reason)`（先留痕后删；Security 面 append-only） |
| 业务审计 Web（C6/G9） | 见 §三.6；路由 `POST /api/audit-logging/business-audit/query`、`GET .../{id}`、`GET .../{id}/detail`（`RequireAuthorization`） |
