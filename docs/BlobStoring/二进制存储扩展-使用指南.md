# 二进制存储扩展使用指南

> **扩展**: `TKWF.Ext.BlobStoring` | **版本**: V0.1.0 | **框架**: .NET 10

本指南帮助消费方快速集成二进制存储扩展，实现本地文件系统 Blob 上传/下载/删除与元数据持久化。

---

## 一、安装

### 1.1 引用扩展项目

```xml
<!-- 消费方 .csproj -->
<ItemGroup>
  <ProjectReference Include="..\..\_Framework\BlobStoring\TKWF.Ext.BlobStoring.csproj" />
</ItemGroup>
```

### 1.2 引用扩展包

扩展经 `[TKWFExtension]` 被 SG1 编译期发现（生成能力清单）。**V4.9.85 起发现不自动启用**——须先声明白名单（见 §1.3），三钩子才接线。

白名单声明后自动注册：`IBlobStorageService` → `LocalStorageService`（Scoped）+ `IBlobRecordStore` → `FreeSqlBlobRecordStore`（Scoped）。

### 1.3 启用扩展（v4.9.85+ 必需）

> **V4.9.85 (ADR47) 起**：扩展不再"发现即启用"。消费方需在领域初始化器上显式声明 `[TKWFEnabledExtension]`，扩展才进入白名单（三钩子执行）。

```csharp
// 消费方领域初始化器（DomainHostInitializerBase<TUserInfo> 子类）
using TKWF.Ext.BlobStoring;

[TKWFEnabledExtension(typeof(BlobStoringExtensionInitializer<>))]
public class MyDomainInitializer : DomainHostInitializerBase<MyUserInfo>
{
    // ...
}
```

若不声明 `[TKWFEnabledExtension]`，扩展的三钩子（ConfigureServices / ConfigureFilters / InitializeAsync）不会执行，DI 注册不会生效。

## 二、配置

### 2.1 appsettings.json

```json
{
  "TKWF": {
    "BlobStoring": {
      "RootPath": "./blobs",
      "IsEnabled": true
    }
  }
}
```

### 2.2 配置选项说明

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| RootPath | string | "./blobs" | Blob 存储根目录（本地文件系统） |
| IsEnabled | bool | true | 是否启用二进制存储 |

## 三、上传 / 下载 / 删除

### 3.1 上传文件

```csharp
public class FileService(IBlobStorageService blobStorage)
{
    public async Task<BlobInfo> UploadFileAsync(Stream stream, string fileName, string contentType)
    {
        // 上传成功返回元数据：Name / Path / ContentType / Size
        // Path 为相对 RootPath 的路径（Guid 子目录隔离，避免文件名冲突），可直接用于后续下载/删除
        return await blobStorage.UploadAsync(fileName, stream, contentType);
    }
}
```

例子：

```csharp
using var stream = File.OpenRead("avatar.png");
var blob = await blobStorage.UploadAsync("avatar.png", stream, "image/png");
Console.WriteLine($"Stored at: {blob.Path}, Size: {blob.Size}");
```

### 3.2 下载文件

```csharp
var stream = await blobStorage.DownloadAsync(blob.Path);
if (stream != null)
{
    // 使用完释放流
    using (stream)
    {
        await stream.CopyToAsync(outputStream);
    }
}
else
{
    // 文件不存在
}
```

> 下载返回 `MemoryStream`（不存在返回 `null`），调用方负责释放。

### 3.3 删除文件

```csharp
var deleted = await blobStorage.DeleteAsync(blob.Path);
// 已存在并删除 → true；不存在或失败 → false（异常静默）
```

### 3.4 存在性检查

```csharp
var exists = await blobStorage.ExistsAsync(blob.Path);
```

## 四、元数据记录

### 4.1 保存记录

`BlobRecordEntity` 与文件存储独立——上传成功后可将元数据记录到 `BlobRecord` 表：

```csharp
public class FileService(IBlobRecordStore recordStore)
{
    public async Task SaveRecordAsync(BlobRecordEntity record)
    {
        await recordStore.SaveAsync(record); // 插入（Id=0）或更新（Id>0，先删后插）
    }
}
```

### 4.2 按 ID / 名称查询

```csharp
var byId = await recordStore.GetAsync(id);
var byName = await recordStore.GetByNameAsync("avatar.png");
```

### 4.3 列表查询

```csharp
// 全部（前 20 条）
var all = await recordStore.GetListAsync();

// 按内容类型过滤 + 分页
var images = await recordStore.GetListAsync(contentType: "image/png", skip: 0, take: 50);
```

### 4.4 删除记录

```csharp
await recordStore.DeleteAsync(recordId);
```

## 五、自定义实现

### 5.1 自定义 IBlobStorageService

若需替换本地文件系统（如 Azure Blob、Amazon S3、MinIO）：

```csharp
// 消费方 ConfigureServices 中
services.AddScoped<IBlobStorageService, AzureBlobStorageService>();
```

TryAdd 语义确保消费方实现优先。`IBlobStorageService` 接口不依赖本地文件系统概念（Path 为相对逻辑路径），可平滑替换后端。

### 5.2 自定义 IBlobRecordStore

若需替换 FreeSql 存储（如 MongoDB、文件）：

```csharp
// 消费方 ConfigureServices 中
services.AddScoped<IBlobRecordStore, MongoBlobRecordStore>();
```

## 六、异常处理

扩展采用**异常静默**模式：

- 文件上传/下载/删除/存在性检查失败时记录 Warning 日志，**不抛出异常**
- 元数据记录读写失败时记录 Warning 日志，**不抛出异常**
- 业务调用不会因文件存储失败而中断

> 唯一例外：`UploadAsync` 的 `content` 参数为 `null` 时抛出 `ArgumentNullException`（编程错误，非运行时故障）。

## 七、实体表结构

`BlobRecordEntity` 映射到 `BlobRecord` 表（SG1 自动生成建表 DTO/DataService）：

| 列名 | 类型 | 说明 |
|------|------|------|
| Id | BIGINT (PK, Identity) | 主键 |
| Name | NVARCHAR(256) | Blob 名称（业务键） |
| Path | NVARCHAR(1024) | 存储路径（相对 RootPath） |
| ContentType | NVARCHAR(128) | MIME 内容类型 |
| Size | BIGINT | 文件大小（字节） |
| Tags | NVARCHAR(MAX) | 标签（JSON 数组字符串） |
| UploaderName | NVARCHAR(128) | 上传者名称 |
| CreateTime | DATETIMEOFFSET | 创建时间 |
| UpdateTime | DATETIMEOFFSET | 更新时间 |
