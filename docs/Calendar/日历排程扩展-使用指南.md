## 1. 快速开始

### 1.1 引用

```xml
<!-- 消费方 .csproj -->
<ProjectReference Include="..\..\_Framework\Calendar\TKWF.Ext.Calendar.csproj" />
```

### 1.2 启用（v4.9.85+ 白名单声明）

```csharp
using TKWF.Ext.Calendar;

[TKWFEnabledExtension(typeof(CalendarExtensionInitializer<>))]
public class MyDomainInitializer : DomainHostInitializerBase<MyUserInfo> { ... }
```

### 1.3 注入使用

```csharp
public class ScheduleService(ICalendarManager calendarManager)
{
    public async Task CreateMeetingAsync()
    {
        // 创建日历
        var team = await calendarManager.CreateCalendarAsync("TEAM", "团队日历", color: "#3498DB");

        // 单次事件（时间必须为 DateTimeKind.Utc）
        await calendarManager.CreateEventAsync(
            team.Id, "项目评审", new DateTime(2026, 9, 9, 10, 0, 0, DateTimeKind.Utc),
            endUtc: new DateTime(2026, 9, 9, 11, 0, 0, DateTimeKind.Utc));

        // 重复事件：每周一/三/五 09:00 站会，共 30 次
        await calendarManager.CreateEventAsync(
            team.Id, "站会", new DateTime(2026, 9, 9, 9, 0, 0, DateTimeKind.Utc),
            recurrenceRule: "FREQ=WEEKLY;BYDAY=MO,WE,FR;COUNT=30");

        // 查询未来 30 天所有 occurrence（日历视图数据）
        var from = DateTime.UtcNow;
        var occurrences = await calendarManager.GetOccurrencesAsync(
            team.Id, from, from.AddDays(30));
    }
}
```

## 2. 日历管理

```csharp
// 创建（Code 库级唯一；重复 Code → 唯一约束异常）
var cal = await calendarManager.CreateCalendarAsync("PERSONAL", "个人日历", description: "私人事宜", color: "#2ECC71");
// 更新（含启停；IsEnabled=false 的日历不再出现在 occurrence 查询）
await calendarManager.UpdateCalendarAsync(cal.Id, name: "个人日历（改名）", isEnabled: false);
// 删除保护：含事件 → InvalidOperationException（请先删除事件）
await calendarManager.DeleteCalendarAsync(cal.Id);
// 查询
var all = await calendarManager.GetCalendarsAsync();          // 全部（含禁用）
var one = await calendarManager.GetCalendarAsync(cal.Id);
```

## 3. 事件维护

```csharp
// 单次事件
await calendarManager.CreateEventAsync(cal.Id, "评审", startUtc, endUtc: endUtc);
// 瞬时事件（无 EndUtc）
await calendarManager.CreateEventAsync(cal.Id, "提醒", startUtc);
// 全天事件（起点自动归一为 UTC 日期午夜；EndUtc = 次日 00:00）
await calendarManager.CreateEventAsync(cal.Id, "休假", new DateTime(2026, 9, 10, 0, 0, 0, DateTimeKind.Utc), allDay: true);
// 重复事件（规则串）
await calendarManager.CreateEventAsync(cal.Id, "周报", startUtc, recurrenceRule: "FREQ=WEEKLY;BYDAY=FR;COUNT=52");

// 更新（改规则/时间 → RecurrenceEndUtc 自动重算）
await calendarManager.UpdateEventAsync(eventId, title: "周报（改）", recurrenceRule: "FREQ=WEEKLY;BYDAY=FR;UNTIL=20271231T235959Z");
// 删除（occurrence 不落库——展开是查询时计算）
await calendarManager.DeleteEventAsync(eventId);
```

**约束**：
- **UTC 契约**：所有时间参数必须 `DateTimeKind.Utc`——传 Local/Unspecified 抛 `ArgumentException`（fail-fast，防止 8 小时级偏移）；
- `EndUtc ≥ StartUtc`（否则 `ArgumentException`）；
- 日历不存在 → `InvalidOperationException`（引用守卫）。

## 4. 重复规则语法（RRULE 子集）

```
FREQ=DAILY|WEEKLY|MONTHLY|YEARLY          # 必填
INTERVAL=n                                 # 每 n 个周期（默认 1；0/负 → 格式异常）
COUNT=n | UNTIL=yyyyMMdd'T'HHmmss'Z'      # 互斥（同现 → 格式异常）；UNTIL 也可 yyyyMMdd（当日 00:00 UTC）
BYDAY=MO,TU,WE,TH,FR,SA,SU                # 仅 WEEKLY（多值逗号分隔；大小写不敏感）
```

| 示例 | 含义 |
|------|------|
| `FREQ=DAILY` | 每天（无限） |
| `FREQ=DAILY;INTERVAL=2;COUNT=10` | 每 2 天，共 10 次 |
| `FREQ=WEEKLY;BYDAY=MO,WE,FR` | 每周一/三/五（无限） |
| `FREQ=WEEKLY;BYDAY=MO;UNTIL=20261231T235959Z` | 每周一，至 2026 年底 |
| `FREQ=MONTHLY;COUNT=12` | 每月（1/31 起始 → 2 月钳制为月末最后一天） |
| `FREQ=YEARLY;COUNT=3` | 每年（2/29 起始 → 非闰年钳制 2/28） |

**展开语义**：
- **UTC 计算**（无时区/夏令时）；**DTSTART 恒为第一 occurrence**；
- **月末钳制**（务实语义，对齐 Google Calendar/Outlook）：31 日在 2 月 → 28/29、4/6/9/11 月 → 30 日；绝对索引无级联漂移（1/31 每月 → 2/28 → 3/31）；
- **半开区间**：occurrence 查询 `[fromUtc, toUtc)`——含 from 不含 to；
- **fail-fast**：未知子句（BYMONTH/BYSETPOS/WKST/BYHOUR 等）、非 WEEKLY 的 BYDAY（含 `1MO` 序数形式）、COUNT/UNTIL 同现、INTERVAL=0/COUNT=0 → `FormatException`；
- **展开上限**：单事件 `maxCount`（默认 1000）+ 合并总收集 `1,000,000` 硬上限——无界规则 + 大范围查询不爆内存。

## 5. occurrence 查询

```csharp
// 按日历 + 时间范围查 occurrence（calendarId 可空 = 全部启用日历）
var result = await calendarManager.GetOccurrencesAsync(
    calendarId: null, fromUtc, toUtc, maxCount: 1000);

// result.Occurrences：按 StartUtc 升序（相等 + EventId 次级键）
foreach (var occ in result.Occurrences)
{
    // EventOccurrence(StartUtc, EndUtc, EventId, CalendarId, Title, AllDay)
    //   EndUtc = occurrence 起点 + 事件时长偏移（AllDay +1 天）
}
// result.Truncated：true = 总数超 maxCount/全局上限被截断（截断的是最晚 occurrence）
```

- 单次事件直接命中（跨范围事件含入）；重复事件展开后二次过滤；
- **IsEnabled=false 的日历默认排除**。

## 6. 生产注意事项

- **建表**：`Calendar` / `CalendarEvent` 两表由框架 `SyncTables` 统一托管（V4.9.92 ADR49），**无手工 DDL 前置**（无 VEntity，无 DBA 建视图负担）。
- **UTC 约定**：全部时间 UTC 存储与计算（消费方展示层自行转换本地时区）；传非 UTC 会立即得到明确异常（非静默偏移）。
- **时区边界**：v0.1.0 不支持时区/夏令时语义——跨时区团队的"本地时间会议"需消费方约定（如统一 UTC 时刻存储，展示层转换）。
- **重复规则边界**：完整 RFC 5545 子句（BYMONTH/BYSETPOS/WKST/EXDATE）不支持；"每月最后一个工作日"需消费方自定义日期后显式列单次事件。
- **多租户隔离**：v0.1.0 不内置租户过滤，多租户场景由消费方自行隔离。

## 7. 边界与语义速查

| 场景 | 行为 |
|------|------|
| 重复 Code 创建日历 | 库级唯一约束拒绝 |
| 日历含事件删除 | `InvalidOperationException`（删除保护） |
| 日历不存在建事件 | `InvalidOperationException`（引用守卫） |
| 传非 UTC 时间 | `ArgumentException`（UTC 契约） |
| `EndUtc < StartUtc` | `ArgumentException` |
| 非法规则串（未知子句/COUNT+UNTIL 同现/INTERVAL=0） | `FormatException`（fail-fast） |
| 无界规则 + 大范围查询 | `maxCount`/全局上限截断（Truncated 标志） |
| AllDay 事件 | 起点归一 UTC 午夜，EndUtc = 次日 00:00，occurrence +1 天 |
| 月末 31 日重复 | 钳制到月末最后一天（务实语义） |
