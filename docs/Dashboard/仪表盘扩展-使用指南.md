# 仪表盘扩展-使用指南

> **扩展**：`TKWF.Ext.Dashboard`（仪表盘数据服务）· **版本**：v0.1.0
> **概念名**：仪表盘数据服务（Dashboard）——Metrics 展示层：JSON 描述符定义 + Widget 数据查询 + 消费 `TKW.Framework.Utility.Metrics` 复合指标
> **技术规范**：见 [_Framework/Dashboard/README.md](../../_Framework/Dashboard/README.md)

---

## 一、快速开始

### 1. 引用扩展

```xml
<!-- 消费方 .csproj -->
<ProjectReference Include="..\..\_Framework\Dashboard\TKWF.Ext.Dashboard.csproj" />
```

### 2. 白名单声明（v4.9.85+ 必需）

扩展不再"发现即启用"——消费方须在领域初始化器上显式声明白名单，三钩子才接线：

```csharp
using TKWF.Ext.Dashboard;
using TKWF.Ext.Metrics;

// metricRef Widget 依赖 Metrics 扩展注册 IMetricCalculatorFactory——两个扩展都要启用
[TKWFEnabledExtension(typeof(DashboardExtensionInitializer<>))]
[TKWFEnabledExtension(typeof(MetricsExtensionInitializer<>))]
public class MyDomainInitializer : DomainHostInitializerBase<MyUserInfo> { ... }
```

声明后自动注册（TryAdd 语义，消费方可覆盖）：
- `IDashboardDataService`（Scoped）——定义查询 + Widget 数据查询
- `DashboardSpecFileProvider`（Singleton）——双路径规格加载
- `DashboardOptions` 绑定 `TKWF:Dashboard` 配置节

### 3. 实现数据源（IDashboardDataProvider）

消费方实现取数——返回数据行 + 字段访问器（Oracle C2：accessor 随行返回）：

```csharp
public class PaymentDataProvider : IDashboardDataProvider
{
    public string Name => "payment-ds";   // 与 dashboard.json 的 dataSource 匹配

    public Task<(IReadOnlyList<object> Rows, Func<object, string, object?> Accessor)> GetDataAsync(
        string widgetName, IReadOnlyDictionary<string, object?>? filters, CancellationToken ct = default)
    {
        // 按 filters（日期范围等）过滤取数
        var rows = QueryPayments(filters);   // IReadOnlyList<PaymentLog>
        Func<object, string, object?> accessor = (source, fieldName) =>
            source.GetType().GetProperty(fieldName)?.GetValue(source);
        return Task.FromResult((Rows: (IReadOnlyList<object>)rows, Accessor: accessor));
    }
}

// DI 注册（消费方领域初始化器或 Program.cs）
services.AddSingleton<IDashboardDataProvider, PaymentDataProvider>();
```

> **accessor 说明**：字段访问委托 `(source, fieldName) → value`——Metrics 计算器按规格参数里的 `*Field` 值（如 `"userIdField": "MemberId"`）经此委托读取字段。生产实现建议用编译委托缓存替代反射（对齐 Metrics 构建期访问器思想）。

### 4. 配置（appsettings.json）

```json
{
  "TKWF": {
    "Dashboard": { "SpecRoot": "docs/dashboard-specs" },
    "Metrics": { "SpecRoot": "docs/analytics-specs" }
  }
}
```

### 5. 定义 Dashboard（dashboard.json）

目录 `docs/dashboard-specs/operations/business-overview.json`：

```json
{
  "name": "business-overview",
  "title": "经营总览",
  "group": "operations",
  "widgets": [
    {
      "name": "today-revenue",
      "type": "numberContainer",
      "row": 0, "order": 0, "width": 1,
      "dataSource": "payment-ds",
      "metricRef": "merchant/payment-metrics:total-revenue"
    },
    {
      "name": "payment-list",
      "type": "list",
      "row": 1, "order": 0, "width": 2,
      "dataSource": "payment-ds"
    }
  ]
}
```

对应的 Metrics 规格 `docs/analytics-specs/merchant/payment-metrics/metric-definitions.json`（Metrics 扩展格式）：

```json
{
  "$schema": "tkwf-metrics-definitions/v1",
  "specKey": "payment-metrics",
  "metrics": [
    { "name": "total-revenue", "calculator": "ratio",
      "parameters": { "numeratorField": "TotalAmount", "numeratorAggregate": "sum",
                      "denominatorField": "PaidCount", "denominatorAggregate": "count" } }
  ]
}
```

### 6. 注入 + 查询

```csharp
public class DashboardController(IDashboardDataService dashboard)
{
    // 查询 Dashboard 定义（布局渲染用）
    public async Task<DashboardDefinition> GetDefinition(string dashKey)
        => await dashboard.GetDashboardDefinitionAsync(dashKey);

    // 查询 Widget 数据（KPI 卡片/图表/列表）
    public async Task<WidgetDataResult> GetWidget(string dashKey, string widgetName)
        => await dashboard.GetWidgetDataAsync(dashKey, widgetName,
            new Dictionary<string, object?> { ["from"] = "2026-09-01", ["to"] = "2026-09-30" });
}
```

## 二、Widget 类型与响应形态

| Widget 类型 | 场景 | 响应填充 | 示例 |
|------------|------|---------|------|
| `numberContainer` | KPI 单值卡片 | `Value` + `Unit` + `Dimensions` | 今日营业额、复购率 |
| `chart` | 趋势/分布图表 | `Slices`（多切片展开）或 `Value`（单值指标） | 每日营业额趋势、漏斗转化 |
| `list` | 明细列表 | `Rows`（数据行） | 最近支付记录 |

**响应 DTO（WidgetDataResult）**：

```csharp
public sealed record WidgetDataResult(
    string WidgetName,
    DashboardWidgetType Type,
    string? MetricName,                                  // metricRef 计算时非空
    object? Value,                                       // numberContainer：单值
    string? Unit,                                        // 指标单位
    IReadOnlyDictionary<string, object?>? Dimensions,    // 单切片维度
    IReadOnlyList<WidgetDataResult>? Slices,             // chart：多切片展开
    IReadOnlyList<object>? Rows);                        // list：明细数据行
```

消费方按 `Type` 分支解析：`numberContainer` 读 `Value`；`chart` 读 `Slices`（每切片含 Value + Dimensions，如 `{ "bucket": "2026-09-01", "value": 100 }`）；`list` 读 `Rows`。

## 三、metricRef 引用模型

`metricRef` = `"domain/specKey:metricName"` 或 `"domain/specKey"`（全量）：

| 格式 | 行为 | 适用 |
|------|------|------|
| `merchant/payment-metrics:total-revenue` | 计算特定指标，返回单值 | KPI 卡片（numberContainer） |
| `merchant/payment-metrics:daily-trend` | 计算多切片指标，展开 Slices | 趋势图表（chart） |
| `merchant/payment-metrics` | 计算规格全部指标，展开 Slices | 多指标图表（chart） |

> **前置依赖**：metricRef Widget 需要 Metrics 扩展启用（`IMetricCalculatorFactory` 注册）。未启用时 Dashboard 首次查询抛 `DashboardDefinitionException`（fail-fast，消息注明启用方式）。

## 四、配置说明

| 配置节 | 键 | 默认 | 说明 |
|--------|-----|------|------|
| `TKWF:Dashboard` | `SpecRoot` | `docs/dashboard-specs` | Dashboard 定义 JSON 根目录 |
| `TKWF:Metrics` | `SpecRoot` | `docs/analytics-specs` | Metrics 指标规格根目录（Dashboard 经 IConfiguration 直读，零冗余） |

## 五、边界与规划

**v0.1.0 不做**（消费方自行承担）：
- 图表渲染/UI 组件——消费方选图表库（Blazor/React 任选）
- 布局持久化/操作者可编辑——JSON 描述符 git-tracked
- 拖拽排序/缩放/实时推送/下钻导航
- 结果缓存/预聚合

**v0.2.0 候选**：布局持久化 + 管理 UI、结果缓存、可选 Blazor 组件包（`TKWF.Ext.Dashboard.UI`）、定时刷新。

## 六、异常处理

| 场景 | 异常 |
|------|------|
| 定义文件缺失 / JSON 损坏 | `DashboardDefinitionException`（含 dashKey + 文件路径） |
| Widget 名重复 / dataSource 缺失 / width 越界 | `DashboardDefinitionException`（含 Widget 名） |
| Widget 未找到 / 数据源未注册 | `DashboardDefinitionException` |
| metricRef 格式非法 / 指标未在规格中定义 | `DashboardDefinitionException` |
| Metrics 扩展未启用 + metricRef Widget | `DashboardDefinitionException`（fail-fast，注明启用方式） |
| Metrics 规格文件缺失 / 结构非法 | `MetricDefinitionException`（Metrics 语义，透传） |
