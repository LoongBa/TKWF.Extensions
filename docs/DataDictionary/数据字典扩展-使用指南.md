# 数据字典扩展使用指南

> **扩展**: `TKWF.Ext.DataDictionary` | **版本**: V0.1.0 | **框架**: .NET 10

本指南帮助消费方集成数据字典扩展，集中管理枚举/下拉/参考数据（性别、状态、类型、国家地区等）。

---

## 一、能力概览

| 能力 | 说明 |
|------|------|
| 字典定义 | 编码/名称/描述/启用——`DictionaryDefinitionEntity` |
| 字典项 | 归属定义的选项（编码/显示名/值/排序/启用）——`DictionaryItemEntity` |
| 按编码查询 | `GetDefinitionWithItemsAsync(code)` 一次返回定义 + 排序后的项 |
| Upsert 幂等 | 定义按 Code、项按 DefinitionId+Code——重复提交更新而非报错 |

---

## 二、安装

### 2.1 引用扩展项目

```xml
<!-- 消费方 .csproj -->
<ItemGroup>
  <ProjectReference Include="..\..\_Framework\DataDictionary\TKWF.Ext.DataDictionary.csproj" />
</ItemGroup>
```

### 2.2 启用扩展（v4.9.85+ 必需）

> **V4.9.85 (ADR47) 起**：扩展不再"发现即启用"。消费方需在领域初始化器上显式声明 `[TKWFEnabledExtension]`，扩展才进入白名单（三钩子执行）。

```csharp
// 消费方领域初始化器（DomainHostInitializerBase<TUserInfo> 子类）
using TKWF.Ext.DataDictionary;

[TKWFEnabledExtension(typeof(DataDictionaryExtensionInitializer<>))]
public class MyDomainInitializer : DomainHostInitializerBase<MyUserInfo>
{
    // ...
}
```

自动注册：`IDictionaryStore`（默认 `FreeSqlDictionaryStore`）+ `IDictionaryManager`（默认 `DictionaryManager`）。

## 三、使用

### 3.1 读取字典（业务侧）

```csharp
// 注入 IDictionaryManager
public class OrderFormService(IDictionaryManager dictionaryManager)
{
    // 一次返回完整字典（定义 + 排序后的项）
    public async Task<DictionaryDefinitionWithItems?> GetGenderOptionsAsync()
        => await dictionaryManager.GetDefinitionWithItemsAsync("Gender");

    // 仅取项列表（按 Order 排序，不含禁用项）
    public async Task<IReadOnlyList<DictionaryItemEntity>> GetStatusItemsAsync()
        => await dictionaryManager.GetItemsAsync("OrderStatus");
}
```

### 3.2 维护字典（管理侧）

```csharp
// 新增/更新字典定义（按 Code 幂等）
await dictionaryManager.UpsertDefinitionAsync(new DictionaryDefinitionEntity
{
    Code = "Gender",
    DisplayName = "性别",
    Description = "用户性别选项"
});

// 新增/更新字典项（按 DefinitionId + Code 幂等）
await dictionaryManager.UpsertItemAsync(new DictionaryItemEntity
{
    DefinitionId = genderDef.Id,
    Code = "Male",
    DisplayName = "男",
    Order = 1
});
```

### 3.3 配置选项

```json
{
  "TKWF": {
    "DataDictionary": {
      "IsEnabled": true
    }
  }
}
```

## 四、实体表结构

| 表 | 说明 | 关键列 |
|----|------|--------|
| `DictionaryDefinition` | 字典定义 | Code（唯一）/ DisplayName / Description / IsEnabled |
| `DictionaryItem` | 字典项 | DefinitionId（索引）/ Code / DisplayName / Value? / Order / IsEnabled |

两表经 SG1 + `FreeSqlTableStructureSynchronizer` 自动建表。

---

## 五、安全语义

- **异常静默**：存储/管理操作失败记录 Warning 日志，不阻塞业务
- **TryAdd 语义**：消费方自定义 `IDictionaryStore`/`IDictionaryManager` 优先
- **Scoped 生命周期**：参与当前请求上下文
- **Upsert 幂等**：重复提交更新而非报错

## 六、常见问题

**Q: 下拉选项如何保证排序稳定？**
A: 字典项 `Order` 字段控制排序（小值在前）；`GetItemsAsync`/`GetDefinitionWithItemsAsync` 自动按 Order 返回。

**Q: 禁用字典项会怎样？**
A: 已禁用项从查询结果排除（`IsEnabled=false`），但仍保留在库中供恢复。

**Q: 能自定义字典存储吗？**
A: 可以实现自定义 `IDictionaryStore`（如 Redis 缓存后端）经 TryAdd 注册——扩展默认 FreeSql 实现不覆盖消费方。

**Q: 需要缓存吗？**
A: V0.1.0 无缓存（每次查库）；V0.2.0 规划按 Definition Code 的内存缓存过期层。
