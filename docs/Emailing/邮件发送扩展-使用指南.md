# 邮件发送扩展使用指南

> **扩展**: `TKWF.Ext.Emailing` | **版本**: V0.1.0 | **框架**: .NET 10

本指南帮助消费方快速集成邮件发送扩展，实现 SMTP 邮件发送与记录持久化。

---

## 一、安装

### 1.1 引用扩展项目

```xml
<!-- 消费方 .csproj -->
<ItemGroup>
  <ProjectReference Include="..\..\_Framework\Emailing\TKWF.Ext.Emailing.csproj" />
</ItemGroup>
```

### 1.2 引用扩展包

扩展经 `[TKWFExtension]` 被 SG1 编译期发现（生成能力清单）。**V4.9.85 起发现不自动启用**——须先声明白名单（见 §1.3），三钩子才接线。

白名单声明后自动注册：`IEmailSender` → `SmtpEmailSender`（Scoped）+ `IEmailRecordStore` → `FreeSqlEmailRecordStore`（Scoped）。

### 1.3 启用扩展（v4.9.85+ 必需）

> **V4.9.85 (ADR47) 起**：扩展不再"发现即启用"。消费方需在领域初始化器上显式声明 `[TKWFEnabledExtension]`，扩展才进入白名单（三钩子执行）。

```csharp
// 消费方领域初始化器（DomainHostInitializerBase<TUserInfo> 子类）
using TKWF.Ext.Emailing;

[TKWFEnabledExtension(typeof(EmailingExtensionInitializer<>))]
public class MyDomainInitializer : DomainHostInitializerBase<MyUserInfo>
{
    // ...
}
```

若不声明 `[TKWFEnabledExtension]`，扩展的三钩子（ConfigureServices / ConfigureFilters / InitializeAsync）不会执行，DI 注册不会生效。

## 二、配置

### 2.1 appsettings.json

```json
{
  "TKWF": {
    "Emailing": {
      "SmtpHost": "smtp.example.com",
      "SmtpPort": 587,
      "SmtpUser": "user@example.com",
      "SmtpPassword": "your-password",
      "DefaultFrom": "noreply@example.com",
      "IsEnabled": true
    }
  }
}
```

### 2.2 配置选项说明

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| SmtpHost | string | "" | SMTP 服务器主机名 |
| SmtpPort | int | 587 | SMTP 服务器端口 |
| SmtpUser | string | "" | SMTP 认证用户名 |
| SmtpPassword | string | "" | SMTP 认证密码 |
| DefaultFrom | string | "" | 默认发件人地址 |
| IsEnabled | bool | true | 是否启用邮件发送 |

## 三、发送邮件

### 3.1 基本发送

```csharp
public class NotificationService(IEmailSender emailSender)
{
    public async Task SendWelcomeEmailAsync(string userEmail)
    {
        await emailSender.SendAsync(new EmailMessage
        {
            To = userEmail,
            Subject = "Welcome!",
            Body = "<h1>Welcome to our platform!</h1>",
            IsHtml = true
        });
    }
}
```

### 3.2 纯文本邮件

```csharp
await emailSender.SendAsync(new EmailMessage
{
    To = "user@example.com",
    Subject = "Password Reset",
    Body = "Your password reset code is: 123456",
    IsHtml = false
});
```

### 3.3 自定义发件人

```csharp
await emailSender.SendAsync(new EmailMessage
{
    To = "user@example.com",
    From = "custom@example.com",  // 覆盖 DefaultFrom
    Subject = "Custom Sender",
    Body = "Hello!"
});
```

### 3.4 多收件人

```csharp
await emailSender.SendAsync(new EmailMessage
{
    To = "user1@example.com,user2@example.com,user3@example.com",
    Subject = "Broadcast",
    Body = "Hello everyone!"
});
```

## 四、邮件记录查询

### 4.1 查询所有记录

```csharp
public class EmailHistoryService(IEmailRecordStore recordStore)
{
    public async Task<List<EmailRecordEntity>> GetAllRecordsAsync()
    {
        return (await recordStore.GetListAsync()).ToList();
    }
}
```

### 4.2 按状态过滤

```csharp
// 只查询发送失败的记录
var failedRecords = await recordStore.GetListAsync("Failed");

// 只查询发送成功的记录
var sentRecords = await recordStore.GetListAsync("Sent");
```

### 4.3 按 ID 查询

```csharp
var record = await recordStore.GetAsync(recordId);
if (record != null)
{
    Console.WriteLine($"Status: {record.Status}, Error: {record.ErrorMessage}");
}
```

## 五、自定义实现

### 5.1 自定义 IEmailSender

若需替换 SMTP 发送（如 SendGrid、Amazon SES）：

```csharp
// 消费方 ConfigureServices 中
services.AddScoped<IEmailSender, SendGridEmailSender>();
```

TryAdd 语义确保消费方实现优先。

### 5.2 自定义 IEmailRecordStore

若需替换 FreeSql 存储（如写文件、Redis）：

```csharp
// 消费方 ConfigureServices 中
services.AddScoped<IEmailRecordStore, FileEmailRecordStore>();
```

## 六、异常处理

扩展采用**异常静默**模式：

- 邮件发送失败时记录 Warning 日志，**不抛出异常**
- 邮件记录保存失败时记录 Warning 日志，**不抛出异常**
- 业务调用不会因邮件发送失败而中断
