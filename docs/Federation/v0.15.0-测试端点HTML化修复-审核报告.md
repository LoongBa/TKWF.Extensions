## 七、失败模式/安全防护

| 失败模式 | 触发场景 | 防护现状 | 判定 |
|---------|---------|---------|------|
| **F1：XSS（external_user_id 等字段注入脚本）** | 微信回调 `openid` 经恶意方构造/污染 payload 字段（外部输入）→ 若未转义直接进 HTML → 脚本在测试页执行 | **✅ 已关闭（代码面）**：四字段（UId/ChannelId/ExternalUserId/ChannelType）**全部**经 `WebUtility.HtmlEncode`——`& < > " '` 五字符全编码，元素内容 `{r.Item2}` 上下文无法逃逸出 `<td>` 引入标签/属性；字段唯一进入点（`trs` 拼接）无旁路；标签名 `r.Item1` 为代码内硬编码字面量（非外部输入） | ✅ **已关闭**；⚠️ 缺回归锁测试（P2） |
| **F2：HTML 结构注入（模板层）** | 页面模板被注入结构（如伪造闭合 `</table>` + 脚本） | ✅ 模板为固定 raw string literal，唯一动态插值 `{trs}` 内为转义后值——注入面与 F1 同源，同关闭；无 URL 插值（无 `href/src` 动态属性） | ✅ 已关闭 |
| **F3：错误路径 JSON 契约漂移** | 错误响应误改 HTML → 程序化消费者解析失败 | ✅ 400/404/403 全路径 `Results.Json`/`ErrorResponse` 保持，diff 上下文零改动；错误路径测试 JSON 反序列化实证通过 | ✅ 已关闭 |
| **F4：票据泄露** | HTML 展示页泄漏 ticket 本体 → 截图/缓存被他人复用 | ✅ HTML 模板零 ticket 插值，仅展示四载荷字段（与旧 JSON 等价）；ticket 仅在 URL 路由段（既有，32 字节高熵 + TTL） | ✅ 无新增面 |
| **F5：微信渲染再失败** | X5/XWEB 对 HTML 兼容性问题（如外部资源、复杂布局、特殊字体） | ✅ 内联样式 + system-ui 字体栈 + `width=device-width,initial-scale=1` viewport + UTF-8 charset——零外部依赖，渲染降级风险低 | ✅ 充分 |
