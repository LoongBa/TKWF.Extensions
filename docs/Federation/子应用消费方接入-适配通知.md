## ⚡ 一句话摘要

**Federation 新增"子应用消费方委托"协议（统一票据 accesscode 安全投递）**——外部 IdP 多通道能力单点部署在 Platform，子应用（XiaoShuTong/EduPlatform 等）**不部署 Federation、不持有平台凭证**，经 4 个标准端点委托 Platform 完成外部认证。两种接入方案：**直接接入**（默认能力，账号统一 Platform）/ **仅共享 Federation**（重点，各应用保留独立账户体系）。

## 一、变更总览

| 对象 | 变更前 | 变更后 |
|------|--------|--------|
| FederationWebExtension | 4 端点（login/jwks/event） | **+4 端点**：`POST {prefix}/authorize/start`（发起）· `GET {prefix}/{platformId}/oauth/{channelId}/callback`（IdP 回调落地）· `POST {prefix}/trust/issue`（已认证签发，direct）· `POST {prefix}/identity/claim`（子应用兑现）——开关经 `TKWF:Federation:Web`（默认开，`RoutePrefix` 默认 `/feberation`） |
| Federation 门面 | ISsoLogin/ISsoChannelFactory/… | **+`ISsoSubAppBridge`**（子应用委托编排门面——state 票据 HMAC + redirect 白名单 + accesscode 签发/兑现） |
| `ISsoChannel` 契约（TrustCenter.Abstractions） | ChannelType/ChannelId/AuthenticateAsync | **+`BuildAuthorizeUrlAsync`（DIM 默认 null）** + `SsoChannelAuthorizeContext/Result`——授权 URL 构造收敛于通道实现（ADR 记录"归装配层"决策反转） |
| TrustCenter.Abstractions | ISsoChannel/IToken2Service/IAccessCodeService | **+`ISsoClientQueryService`**（GetInfo/IsOriginAllowed/ValidateClientCredential 只读校验面）+ `SsoClientInfo` **从 TrustCenter 主包迁移**（同命名空间） |

## 二、适配方案矩阵（三方）

| 消费方 | 方案 | 适配动作 |
|--------|------|---------|
| **Platform 站**（DMP-Lite） | 认证中枢（档位④） | 装配 FederationWebExtension（新端点默认开）；如需子应用委托，注册各子应用为 SsoClient（`ISsoClientService.RegisterAsync` origin 白名单） |
| **XiaoShuTong / EduPlatform** | **仅共享 Federation**（保留本地 AuthCenter 账户体系） | 见 §三·模式 A——外部 IdP 登录经 Platform 委托，本地建号 |
| **AdminUI / UserH5 站**（DMP-Lite） | **直接接入**（默认能力，账号统一 Platform） | 见 §三·模式 B——trust/issue 已认证签发，本地业务 uid = Platform uid |
| 其他未来子应用 | 按需选择 | 直接接入（零本地账户）或仅共享 Federation（保留本地账户） |

## 三、逐项适配指引

### 模式 A：仅共享 Federation（XiaoShuTong/EduPlatform——账户本地保留）

**子应用侧（零扩展装配）**：
```csharp
// ① 保留本地 AuthCenter 实例（现状不动——账户体系自治）
[TKWFEnabledExtension(typeof(AuthCenterExtensionInitializer<>))]
public class XstDomainInitializer : DomainHostInitializerBase<XstUserInfo> { ... }

// ② 子应用作为 SsoClient 注册到 Platform（运营侧一次性——origin 白名单 = 子应用回调域）
await user.Use<ISsoClientService>().RegisterAsync(
    originWhitelist: ["https://xst.loongba.cn"],
    scopes: ["profile:basic"]);

// ③ 前端"微信登录"→ 子应用后端 → Platform {prefix}/authorize/start（redirect=子应用回调，state=子应用会话）
// ④ 用户跳微信 → 微信回调 Platform {prefix}/{platformId}/oauth/{channelId}/callback → Platform 302 回子应用（code + sub_state）
// ⑤ 子应用后端 → Platform {prefix}/identity/claim（app_id + client_secret + code）→ 取 (channel_id, external_user_id)
// ⑥ 子应用本地：PlatformAccountMap (channel_id, external_user_id) → 查/建本地 uid → 签本地 token1 → 登录成功
```

**关键语义**：`ISsoLogin` 纯通道认证（无建号副作用）→ 外部身份**不在 Platform 建号**——账户 100% 留在子应用本地，**单 uid 空间**。

### 模式 B：直接接入（AdminUI/UserH5——账号统一 Platform）

```
① 用户已登录 Platform（Bearer token1）
② 子应用前端 → Platform POST {prefix}/trust/issue（已认证）→ 302 回子应用（code）
③ 子应用后端 → POST {prefix}/identity/claim → 取 platform_uid → 本地业务 uid = platform_uid（不建 AuthAccount）→ 本地会话
```

### Platform 侧（认证中枢装配——一次性）

```csharp
// Program.cs——FederationWebExtension 新端点默认开（Options 开关可关）
.UseWebExtensions<DmpPlatformUserInfo>(e =>
{
    e.Add<AuthCenterWebExtension<DmpPlatformUserInfo>>(x => { x.RestoreUser = ...; });
    e.Add<FederationWebExtension<DmpPlatformUserInfo>>();
});
```
```jsonc
"TKWF": { "Federation": { "Web": {
  "RoutePrefix": "/feberation",
  "AuthorizeEndpointEnabled": true, "OauthCallbackEndpointEnabled": true,
  "TrustIssueEndpointEnabled": true, "IdentityClaimEndpointEnabled": true } } }
```
> ⚠️ `trust/issue` 须 `AuthCenterWebExtension` 同装配（已认证帧）；`authorize/start` 匿名端点建议配 RateLimitingWebExtension IP 限流（防滥用）。

## 四、破坏性变更汇总

| # | 变更 | 级别 | 适配动作 |
|---|------|------|---------|
| 1 | `ISsoChannel` 增 `BuildAuthorizeUrlAsync`（DIM 默认 null） | 非破坏（编译） | 平台库已覆盖 5 库（WeChat/QQ/Alipay/DingTalk/WeCom）；OIDC 系（Google/Microsoft）DIM null（标准 OIDC 归装配层/消费方标准流）——如需统一走 `{prefix}/authorize/start` 后续补 |
| 2 | TrustCenter.Abstractions 增 `ISsoClientQueryService`；`SsoClientInfo` 迁移 | 非破坏 | TrustCenter 主包 `ISsoClientService` 已继承——消费方 `using TKWF.Ext.TrustCenter` 不变，类型位置迁移零感知 |
| 3 | FederationWebExtension 增 4 端点 + Options 4 开关 | 非破坏（默认 true） | Platform 装配即得；不需要可关（如仅本地登录可关 TrustIssueEndpointEnabled） |

**结论**：**零强制迁移**——全部新增能力（非破坏）；消费方按需选用。子应用侧唯一新增 = HttpClient 客户端（start/claim）+ 本地建号逻辑 + SsoClient 注册（一次性）。
