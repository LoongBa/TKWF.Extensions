# 平台网关模板 开发指南（TKWF.Federation.{平台}）

> **定位**: 国内总规划 §三「平台网关通用模式」的**权威固化文档**——新平台开发的第一参考（N1 平台网关通用模板，2026-10-06 落地）。
> **事实源**: `_Framework/Federation.WeChat/`（微信先例——**权威事实源**，模板对齐提炼非重构，F5）+ `_Framework/Federation.WeCom/`（第 9 组件 AuthorizeUrlBuilder 先例）+ `_Framework/Federation.DingTalk/`（第二个完整形态实例）+ `_Framework/Federation.Oidc/`（OIDC 形态——**N1 不覆盖**，走 M1 基座）。
> **关键约束**: 平台网关 = **纯库**（无 Initializer 无 `[TKWFExtension]` 零持久化零 Store——tkwf-extension 铁律）；`ISsoChannel` 窄适配；凭证自持；信任根一票否决（有入站回调平台）；不引 AspNetCore；库 → Federation 扩展单向依赖。
> **可复制脚手架**: `_Framework/Federation.Template/`（T2，占位符 `{Platform}`/`{Namespace}`/`{platform}`）+ 测试模板 `_Tests/Extension.Federation.Template.Tests/`（T3）。

### 2.1 组件 1 出站客户端 `{Platform}ApiClient.cs`

**固定形态**（对齐 `WeChatApiClient.cs`）：

- **typed client**：`AddHttpClient<{Platform}ApiClient>()` 注册；ctor 收 `HttpClient` + `IOptions<{Platform}Options>` + `ILogger<{Platform}ApiClient>`（DI 生命周期托管，避免 HttpClient 悬挂 socket）；
- **access_token L1 缓存**：`ConcurrentDictionary<string, CachedToken>` + `SemaphoreSlim(1,1)` 并发锁防 stampede + 双检 + **提前 5 分钟过期刷新**（`DateTime.UtcNow.AddSeconds(expiresIn).Subtract(TokenEarlyRefresh)`）；
- **code→external_uid 一次性**：结果**不缓存**（一次性 code）；
- **用户信息响应裁剪**：`JsonDocument` 解析 + 字段可选（`TryGetProperty`）+ 缺省降级 null；
- **凭证解析**：从 `{Platform}Options.Channels` 按凭证键精确匹配（`ResolveCredential`——凭证自持 Oracle P2-4，不经 Authentication `IPlatformCredentialService`）；
- 错误处理：平台业务错误（errcode 等）抛 `InvalidOperationException`；响应非 JSON 抛 `JsonException`（通道统一 catch 转失败结果）；
- **平台差异点**：令牌端点 / 用户信息端点 URL 与响应结构 / 是否缓存用户级 token（QQ = 用户级 authorization_code grant **不缓存**——N3 Oracle P1-5）。

### 2.2 组件 2 OAuth 通道 `{Platform}OauthChannel.cs`

**固定形态**（对齐 `WeChatOauthChannel.cs`）：

```csharp
[DiContractIgnore]
public sealed class {Platform}OauthChannel : DomainServiceBase, ISsoChannel
{
    private readonly {Platform}ApiClient _api;
    private readonly {Platform}ChannelConfig _channel;

    public {Platform}OauthChannel(IDomainUser user, {Platform}ApiClient api, IOptions<{Platform}Options> options)
        : base(user) { /* _channel = Channels.FirstOrDefault()（选区）——缺配置抛 InvalidOperationException */ }

    public string ChannelType => "{platform}_oauth";
    public string ChannelId => _channel.ChannelId;

    public async Task<SsoChannelAuthResult> AuthenticateAsync(SsoChannelAuthContext context, CancellationToken ct = default)
    {
        // 缺 code → 失败（FailReason="{PLATFORM}_CODE_REQUIRED"）
        // code 换 external_uid（经 ApiClient）→ 成功（AuthLevel=2）
        // API/网络/JSON 错误 → 统一失败（FailReason 携带机器可读消息）
    }
}
```

- **继承 `DomainServiceBase`**（经基类 `User` 取上下文——tkwf-extension 铁律）；`[DiContractIgnore]` 豁免 DI001（运行时手写注册）；
- **channel 业务参数经 Options 注入**，不占 ctor `IDomainUser` 槽（ADR92 兼容）；
- **authorize 构造归装配层**（通道只收 code——state 生成/会话绑定/回调校验归装配层/消费方，通道不感知 state）；
- **注册**：`TryAddEnumerableConstructible<ISsoChannel, {Platform}OauthChannel>()`（ADR92 集合版守卫工厂——帧内 CurrentAopUser 供给 IDomainUser）；
- 平台差异点：授权形态（跳转 vs 扫码）/ 用户标识字段（openid/unionid/user_id/external_uid 双策略）。

### 2.3 组件 3 事件/回调通道 `{Platform}EventChannel.cs`（可选——有入站回调平台）

**固定形态**（对齐 `WeChatEventChannel.cs`）：

- `ISsoChannel`（`ChannelType="{platform}_event"`）——入站验签 + 解密 + `FromUserName`→external_uid；
- **信任根一票否决**：验签失败即拒（FailReason=`{PLATFORM}_SIGNATURE_INVALID`），绝不解密伪造密文；
- Context 参数（装配层接收端点传入）：`signature`/`timestamp`/`nonce`/`msg_encrypt`（平台参数名差异收敛于此——WeChat 兼容 `msg_signature`/`signature` 双命名）；
- 解密失败/格式非法 → 降级失败（`{PLATFORM}_EVENT_DECRYPT_FAILED`）；
- 平台差异点：验签算法（msg_signature/AES/RSA）+ 事件体结构 + 追加闸门（WeCom ReceiveId 校验 P1-1）。

### 2.4 组件 4 验签逻辑类 `{Platform}EventCrypto.cs`（可选——有入站回调平台）

**固定形态**（对齐 `WeChatEventCrypto.cs`，纯逻辑类，收 `byte[]`/`Stream`/`string`）：

- 验签：平台签名公式（如 `SHA1(sort(token,timestamp,nonce,msg_encrypt))`）——**恒定时间比对**（`CryptographicOperations.FixedTimeEquals`，防时序攻击；签名长度不符直接 false 不抛——防 500 泄漏）；
- 解密：平台加密算法（如 AES-256-CBC，EncodingAESKey 派生密钥）；
- 提取：从解密体取身份标识（FromUserName 等）；
- `EncryptMsg` 测试辅助：与解密严格对称（构造合法正向样本）；
- `internal`：仅本库通道 + 测试（`InternalsVisibleTo`）消费。

### 2.5 组件 5 配置 `{Platform}Options.cs`（⚠️ 按先例定型——与方案 §2.1 差异注记）

> **模板定案（2026-10-06，F5 权威事实源）**：N1 方案 §2.1 原列 `{Platform}ChannelConfig.cs` 独立文件，但 **WeChat/WeCom/Google 先例均无独立文件**——`{Platform}ChannelConfig` 类与 `{Platform}Options` 类**同文件**（`WeChatOptions.cs` 先例：类而非 record）。模板按先例定型：`{Platform}Options.cs` 单文件含两类型。若未来平台凭证字段特别多，可拆独立文件（先例无，YAGNI 不预设）。

```csharp
public class {Platform}ChannelConfig
{
    public string ChannelId { get; set; } = "";      // channel 实例 id（ISsoChannel.ChannelId 选区依据）
    public string AppId { get; set; } = "";          // 平台 AppId（凭证解析键）
    public string AppSecret { get; set; } = "";      // 平台 AppSecret（生产 AES-GCM 密文或装配注入，永不明文进配置库）
    // 有入站回调平台追加：Token（验签令牌）+ EncodingAESKey（43 字符消息加解密密钥）
    // 平台差异点：CorpId/AgentId（WeCom）、EnableUnionId 开关（QQ）等
}

[Options("TKWF:Federation:{Platform}")]
public class {Platform}Options
{
    public List<{Platform}ChannelConfig> Channels { get; set; } = [];
}
```

- `[Options("TKWF:Federation:{Platform}")]`：SG1 在消费方生成 GeneratedOptionsBindings，宿主启动期自动绑定（对齐先例）；亦可在消费方 ConfigureExtensions 编程覆盖；
- **凭证自持**（Oracle P2-4）：channel 凭证归平台库自持（Options 节），**不复用** Authentication `IPlatformCredentialService`——开发明文 appsettings.json；生产 AES-GCM 密文或装配注入（K8s secret mount）。

### 2.7 组件 7 注册扩展 `{Platform}FederationServiceCollectionExtensions.cs`（固定形态）

```csharp
public static class {Platform}FederationServiceCollectionExtensions
{
    public static IServiceCollection Add{Platform}FederationChannels(
        this IServiceCollection services, Action<{Platform}Options>? configure = null)
    {
        ArgumentNullException.ThrowIfNull(services);

        // ⚠️ 禁止 BuildServiceProvider 提前解析（临时根容器 + Scoped 捕获异常）——
        //    一律 AddOptions().Configure 延迟应用配置（对齐 WeChatFederationServiceCollectionExtensions.cs:37）
        services.AddOptions<{Platform}Options>().Configure(o => configure?.Invoke(o));

        // 出站客户端：typed client（ctor 收 HttpClient——AddHttpClient 生命周期托管）
        services.AddHttpClient<{Platform}ApiClient>();

        // ISsoChannel 多实现集合守卫工厂（ADR92）
        services.TryAddEnumerableConstructible<ISsoChannel, {Platform}OauthChannel>();
        // 有入站回调平台追加：
        // services.TryAddEnumerableConstructible<ISsoChannel, {Platform}EventChannel>();

        return services;
    }
}
```

**命名空间**：`Microsoft.Extensions.DependencyInjection`（消费方 `builder.Services.AddXxxFederationChannels()` 直接可调）；**库无 Initializer 无 `[TKWFExtension]`**（纯库判据——注册责任归库侧扩展方法，消费方/装配层调用）。

## 五、信任根分档

| 平台入站能力 | 信任根形态 | 说明 |
|-------------|-----------|------|
| 有入站回调（微信/钉钉/企业微信） | **入站验签一票否决**（组件 3/4） | 验签失败即拒，无降级无旁路；恒定时间比对；漏验 = 可伪造任意 external_uid = 体系崩溃 |
| 无入站回调（QQ/支付宝出站面/B站/小红书/OIDC） | **出站换取链**（组件 1/2） | code 一次性 + state 会话绑定防 CSRF（归装配层）+ client_secret/私钥换取 + **redirect_uri 一致性校验**（OAuth RFC 6749 §4.1.3——code 换 token 时须与授权时一致）+ id_token JWKS 验签（OIDC 适用） |

> P5 适用范围澄清（Oracle 评审 P1-5）：一票否决针对**入站回调/事件验签**；无入站回调平台降级为出站换取链——**非违规**。
