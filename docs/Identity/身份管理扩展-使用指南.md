# 身份管理扩展使用指南

> **扩展**: `TKWF.Ext.Identity` | **版本**: V0.1.0 | **框架**: .NET 10

本指南帮助消费方集成身份管理扩展，实现用户、角色、用户角色分配与凭据验证。

---

## 一、能力概览

| 能力 | 说明 |
|------|------|
| 用户管理 | 创建/查询/更新/删除用户，密码散列存储 |
| 凭据验证 | `VerifyCredentialsAsync`——供登录钩子调用 |
| 角色管理 | 创建/删除角色，系统角色保护 |
| 角色分配 | 用户-角色多对多分配，登录时填充 Roles |
| 种子初始化 | 幂等创建 Admin 系统角色 |

**与主框架的关系**：登录 API 复用框架 `AuthController<TUserInfo>`；密码散列复用 `PasswordHasher`（PBKDF2）；角色判定复用 `IUserInfo.Roles` + `AuthorityFilterAttribute`。

---

## 二、安装

### 2.1 引用扩展项目

```xml
<!-- 消费方 .csproj -->
<ItemGroup>
  <ProjectReference Include="..\..\_Framework\Identity\TKWF.Ext.Identity.csproj" />
</ItemGroup>
```

### 2.2 启用扩展（v4.9.85+ 必需）

> **V4.9.85 (ADR47) 起**：扩展不再"发现即启用"。消费方需在领域初始化器上显式声明 `[TKWFEnabledExtension]`，扩展才进入白名单（三钩子执行）。

```csharp
// 消费方领域初始化器（DomainHostInitializerBase<TUserInfo> 子类）
using TKWF.Ext.Identity;

[TKWFEnabledExtension(typeof(IdentityExtensionInitializer<>))]
public class MyDomainInitializer : DomainHostInitializerBase<MyUserInfo>
{
    // ...
}
```

自动注册：`IUserStore`（默认 `FreeSqlUserStore`）+ `IRoleStore`（默认 `FreeSqlRoleStore`）+ `IUserManager`（默认 `UserManager`）。

## 三、使用

### 3.1 创建用户

```csharp
// 注入 IUserManager
public class AuthService(IUserManager userManager)
{
    public async Task<UserEntity?> CreateUserAsync(string name, string password, string displayName)
        => await userManager.CreateUserAsync(name, password, displayName);
}
```

密码自动用 `PasswordHasher` 散列（PBKDF2 + 350k 迭代 + 随机盐）。

### 3.2 登录衔接（关键）

消费方 `DomainUserHelperBase<TUserInfo>` 子类中调用凭据验证 + 角色加载：

```csharp
// 消费方 UserHelper
private readonly IUserManager _userManager;

protected override async Task<MyUserInfo> OnLoginByPasswordAsync(
    DomainUser<MyUserInfo> user, string userName, string credential, EnumLoginFrom loginFrom)
{
    var idUser = await _userManager.VerifyCredentialsAsync(userName, credential);
    if (idUser == null) throw new InvalidCredentialException();

    // 加载用户角色 → 填充 IUserInfo.Roles
    var roles = await _userManager.GetUserRolesAsync(idUser.Id);

    // 框架 IsInRole / Permissions 角色级判定自动工作
    return CreateUserInstance(idUser.UserName, idUser.DisplayName, roles.Select(r => r.Name));
}
```

### 3.3 角色分配

```csharp
// 为用户分配角色（全量替换）
await userManager.AssignRolesAsync(userId, new long[] { adminRoleId, editorRoleId });

// 读取用户角色
var roles = await userManager.GetUserRolesAsync(userId);

// 移除角色
await userManager.RemoveRoleAsync(userId, roleId);
```

### 3.4 创建/删除角色

```csharp
// 创建角色（isSystemRole: true 表示系统内置，不可删除）
var admin = await userManager.CreateRoleAsync("Admin", "管理员", isSystemRole: true);

// 删除角色（系统角色/已分配角色返回 false）
var deleted = await userManager.DeleteRoleAsync(roleId);
```

### 3.5 修改密码

```csharp
await userManager.ChangePasswordAsync(userId, "newPassword123");
```

### 3.6 配置选项

```json
{
  "TKWF": {
    "Identity": {
      "PasswordMinLength": 6,
      "IsEnabled": true
    }
  }
}
```

## 四、实体表结构

| 表 | 说明 | 关键列 |
|----|------|--------|
| `IdentityUser` | 用户 | UserName / NormalizedUserName / PasswordHash / Email / Phone / IsActive |
| `IdentityRole` | 角色 | Name / DisplayName / IsSystemRole |
| `IdentityUserRole` | 用户-角色映射 | UserId / RoleId |

三表经 SG1 + `FreeSqlTableStructureSynchronizer` 自动建表。

---

## 五、安全语义

- **密码散列**：主框架 `PasswordHasher`（PBKDF2-SHA256，350k 迭代，随机盐），明文不落库
- **异常静默**：存储/管理操作失败记录 Warning 日志，不阻塞业务
- **TryAdd 语义**：消费方自定义 `IUserStore`/`IRoleStore`/`IUserManager` 优先
- **系统角色保护**：`IsSystemRole=true` 的角色不可删除

## 六、常见问题

**Q: 登录时如何让 Permissions 的角色级权限自动生效？**
A: 在 `OnLoginByPasswordAsync` 中调用 `GetUserRolesAsync` 并把角色名填入 `IUserInfo.Roles`——Permissions 的 `PermissionChecker` 会按 `IUserInfo.Roles` 做角色级判定。

**Q: 需要账户锁定/密码重置吗？**
A: V0.1.0 未内置。主框架有 `IAccountLockoutPolicy`/`IPasswordResetFlow` 扩展点，V0.2.0 计划提供默认实现；当前消费方可实现接口自定义。

**Q: 能自定义用户表吗？**
A: 扩展默认 `IdentityUser` 表。若需扩展字段，消费方可继承 `UserEntity` 或实现自定义 `IUserStore` 替换（TryAdd 语义）。
