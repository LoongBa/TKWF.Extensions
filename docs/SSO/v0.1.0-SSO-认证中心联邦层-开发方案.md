## 一、本版目标

- **核心交付**：`TKWF.Ext.SSO` v0.1.0——认证中心联邦层，覆盖：
  1. **契约包前置**：`TKWF.Ext.Authentication.Abstractions` 拆出 SSO 消费面契约（非破坏性——命名空间不变、接口签名不变）
  2. **应用注册**：`SsoClientEntity`（app_id + origin 白名单 + scope + client credential——下游 SP 接入点）
  3. **授权码 accesscode**：`SsoAccessCodeEntity`（120s 单次原子 CAS + SHA256 存储 + PKCE 可选 + 防重放）
  4. **token2 契约**：ES256 自包含 JWT（sub=uid / aud=target_app_id / TTL 300s / jti 单次 / scope）+ **独立密钥域**（ECDSA P-256 + kid 轮转 + JWKS 分发端点）
  5. **profile API**：server-to-server（app client credential + scope 强制 + 不回 openid/channel_id + 审计）
  6. **联盟锚点数据模型**：`AuthAccount.FederationAnchorOpenId` 新列 + `PlatformAccountMapEntity` 扩展承载 channel_id + openid2（方案 A）
  7. **`/sso/*` 端点契约**：`/sso/login`（OAuth 代理入口）/ `/sso/issue`（channel Issue）/ `/sso/auth`（code 消费）/ `/.well-known/jwks.json` / `/sso/api/v1/profile`
- **完成定义（DoD）**：Abstractions 拆包（非破坏）+ SSO 8 组件落地 + SG1 实体/DataService 委托红线合规（零 IEntityDAC/IFreeSql 直注入）+ xCodeGen `.g.cs` 入库 + 测试（含消费方白名单装配 + 双通道时序 + 防重放/防开放重定向负路径）+ README + 使用指南 + slnx 接线 + 全量回归不破坏。

### 5.2 token2 契约（ES256，独立密钥域）

```json
{
  "alg": "ES256", "kid": "sso-key-2026-10",
  "iss": "https://api.lexue.loongba.cn",
  "sub": "<uid>",
  "aud": "<target_app_id>",
  "iat": 1722240000, "exp": 1722240300,
  "jti": "uuid",
  "scope": "profile:basic"
}
```

- **明确不放**：openid / phone / channel_id（隐私最小化 + 解耦应用与渠道，设计文档 §6.2）
- **签名**：手写 ES256（BCL `ECDsa.Create(ECCurve.NamedCurves.nistP256)`，零第三方依赖——对齐 Authentication 手写 RS256 先例）；`CryptographicOperations.FixedTimeEquals` + EC 曲线强制 P-256 + exp/iat 校验 + kid 白名单 + iss 校验 + Base64Url 边界
- **独立密钥域（Oracle P2-5 确认）**：SSO 密钥 = ECDSA P-256 PEM 持久化（`SsoOptions.SigningKeyPath`，**PKCS#8 格式** `ExportPkcs8PrivateKey()`——对齐 RS256 先例；公钥 `ExportParameters(false)` → x/y 坐标 Base64Url RFC 7517 §6.2.2），kid 轮换（`SigningKeys` 列表 + `CurrentKid`）；生产缺密钥 fail-fast；**与 Authentication RS256 密钥域完全独立、互不干扰**
- **DevEcKeyCache（Oracle P2-3）**：开发模式临时 EC 密钥复用 V0.5.3 `DevRsaKeyCache` 双重校验锁 + `ResetForTests()` 模式（`LoadKeysCore` dev 分支经缓存取——避免重蹈"每实例各自生成密钥 → INVALID_SIGNATURE"缺陷）
- **JWKS**：`GET /.well-known/jwks.json` 公开分发（kid + x/y 坐标，RFC 7517）；目标应用凭 kid 缓存公钥离线验签
- **吊销**：短 TTL 为主（300s）；用户封禁/解绑 → jti 吊销列表（profile API 在线校验），app session 周期性 re-check（设计文档 §6.2）

### 5.3 accesscode（授权码，SSO 自建）

| 字段 | 规格 |
|---|---|
| 生成 | CSPRNG 32 字节 `base64url` |
| TTL | **120 秒**（Oracle P2-2：60s 偏紧，点击延迟） |
| 单次 | 原子 CAS（`UPDATE ... WHERE used=false`），重放即拒 + 告警 |
| 存储 | 只存 `SHA256(code)` 索引，不存原文 |
| PKCE | **可选保留**（Oracle P2-1）：`code_verifier_hash` 列 + 校验（defense in depth；通道 B 非 public client，非强制） |
| 关联字段 | `channel_id, openid(仅审计), uid, target_app_id, scope, exp, used, ip, created_at` |

**与既有 `IOAuthTicketService` 边界（Oracle 3.3 并存路径）**：既有 = 单应用票据（login/bind + PKCE + TTL 5min，服务认证中心内部"票据换令牌"）；SSO accesscode = 联邦授权码（channel_id + target_app_id + scope，服务跨应用联邦流）——**语义不同，不迁移不合并**，各自独立表/独立服务。

### 5.4 应用注册（SP 接入）

**`SsoClientEntity`**：

| 列 | 类型 | 说明 |
|---|---|---|
| AppId | string(64) 唯一 | 目标应用 id（token2 `aud`） |
| OriginWhitelist | string(512) JSON | 注册精确 origin（scheme+host）集合——**防开放重定向**（设计文档 §8.4） |
| Scopes | string(256) JSON | 该应用注册范围（默认 `profile:basic`） |
| ClientSecretEncrypted | string | AES-GCM 加密（`SsoOptions.ClientSecretKeyPath` 派生密钥，DataService 边界加解密——对齐 `PlatformCredentialEntity` 先例） |
| **HmacSecretEncrypted** | string | **per-channel + per-app HMAC 密钥**（AES-GCM 加密，同 ClientSecret 机制）——`/sso/issue` 验签密钥从此解密派生（**Oracle P1-4**） |
| IsEnabled | bool | |
| CreateTime / UpdateTime | | UTC |

> **HMAC 密钥载体裁定（Oracle P1-4）**：`/sso/issue`（通道 B）验签密钥 = `SsoClientEntity.HmacSecretEncrypted`（per-channel + per-app，公众号后端持有对称副本）——**不复用 `PlatformCredentialEntity`**（语义不同：PlatformCredential 是 IdP 平台凭证如微信 AppSecret，HMAC 是 SSO 与公众号后端的通道密钥）。
> **channel 密钥归属（Oracle P2-4）**：channel 的 IdP 凭证（如微信 AppId/AppSecret）归**平台适配扩展自持**（`TKWF.Ext.SSO.WeChat` 经 PlatformCredential 或自有配置）；SSO 主包只持 HMAC 通道密钥 + SSO 签名密钥（EC）。

**校验规则**：`/sso/login` 按 `target_app_id` 查注册（404 未注册 / 403 禁用）；`/sso/auth` 302 目标**仅允许**落在 OriginWhitelist 精确 origin（**不接受自由 `redirect_uri` 参数**）。

```csharp
public interface ISsoAccountLinkService          // SSO.WeChat 评审 P1-1 补全（写面）
{
    Task<SsoAccountDto?> GetByFederationAnchorAsync(string federationAnchorOpenId, CancellationToken ct = default);
    Task<SsoAccountDto> SetFederationAnchorAsync(string uid, string federationAnchorOpenId, CancellationToken ct = default);
    // 联盟锚点写面：SetFederationAnchorAsync 写 AuthAccount.FederationAnchorOpenId（一对一）；GetByFederationAnchorAsync 反查直认
}
public interface ISsoChannelMapService
{
    Task<SsoChannelMapDto?> GetByChannelAsync(string channelId, string externalUserId, CancellationToken ct = default);
    Task<SsoChannelMapDto> LinkAsync(string uid, string channelId, string externalUserId, CancellationToken ct = default);
    // DTO：uid / channel_id / external_user_id
}
public sealed record SsoAccountDto(string UId, string? FederationAnchorOpenId, string? Nickname, string? AvatarUrl, int AuthLevel);
public sealed record SsoChannelMapDto(string UId, string ChannelId, string ExternalUserId);
```

- **实现类留 Authentication 主包**（`AuthAccountQueryService : ISsoAccountQueryService + ISsoAccountLinkService`、`PlatformAccountMapService : ISsoChannelMapService`，委托既有 DataService）——Abstractions 只放接口 + DTO（对齐 UserCenter.Abstractions 先例，Oracle P1-1）
- **既有 `IAuthAccountQueryService`/`IPlatformAccountMapService` 签名不动**（返回完整实体，服务既有消费方）——非破坏性
- **鉴权**：server-to-server——`Authorization: Bearer <app client credential>` + `X-App-Id`（设计文档 §5.7）；credential 校验 + scope 强制 + 审计
- **数据源**：经 `ISsoAccountQueryService` 读 SsoAccountDto；**不依赖 UserCenter**（组合矩阵第三形态无 UserCenter 也能工作；未来如需用户中心聚合可承接 `IUserProfileSource`）

### 5.6 channel 契约（IdP 适配器接口，供平台适配扩展实现）

```csharp
public interface ISsoChannel : IDomainService       // Oracle P2-2：ADR92 约束 where TInterface : IDomainService
{
    string ChannelType { get; }                 // wechat_oauth / wechat_event / google_oidc / ...
    string ChannelId { get; }                   // 实例 id（微信 = 公众号 id）
    Task<SsoChannelAuthResult> AuthenticateAsync(SsoChannelAuthContext context, CancellationToken ct = default);
    // 身份获取流程：OAuth 代理（取 external_user_id）/ Issue 票据（形态 B）/ 未来其他
}
public sealed record SsoChannelAuthContext(IReadOnlyDictionary<string, string?> Parameters);   // 可扩展键值模型
public sealed record SsoChannelAuthResult(bool Success, string? ExternalUserId, string? FailReason, AuthLevel AuthLevel);
```

- **可扩展上下文模型**（区别于既有 `ProviderAuthenticateContext` 扁平 record 缺陷——探索确认是既有多渠道主要摩擦点）：`SsoChannelAuthContext` 用 `IReadOnlyDictionary<string, string?>` 承载渠道专有参数，新增渠道**不改签名**（类型安全细化见可选优化 1）
- **与既有 `IAuthenticationProvider` 边界（Oracle P2-3）**：既有 Provider = 认证中心**内部认证方式**（Sms/WeChat，服务 token1 签发）；`ISsoChannel` = **联邦 IdP 适配**（Google/Apple/微软等外部身份源，服务 token2 联邦流）——两套契约并存，平台适配扩展实现 `ISsoChannel` 而非 `IAuthenticationProvider`
- **注册**：`TryAddEnumerableConstructible`（对齐既有 Provider 集合 + ADR92）；平台适配扩展 Initializer 追加实现，未注册通道自然跳过

### 5.7 端点契约（装配层映射，SSO 提供 Service 层）

| 端点 | 方法 | 功能 | 归属 |
|---|---|---|---|
| `/sso/login?target_app_id=X&state=<随机>` | GET | OAuth 代理入口（形态 A）/ 形态 B 引导页 | SSO Service + 装配映射 |
| `/sso/issue` | POST | 形态 B：channel → accesscode（HMAC 验签 + ts±60s + nonce 去重） | SSO Service + 装配映射 |
| `/sso/auth?code=<code>` | GET | 消费 accesscode（原子 CAS）→ 302 `https://<origin>/auth/callback#t=<jwt>` | SSO Service + 装配映射 |
| `/.well-known/jwks.json` | GET | 公钥分发（kid） | SSO（框架级端点） |
| `/sso/api/v1/profile?uid=<uid>` | GET | server-to-server 档案（scope 强制 + 审计） | SSO Service + 装配映射 |

- **防开放重定向**：`/sso/login` 的 `target_app_id → OriginWhitelist` 精确 origin；`/sso/auth` 302 仅注册 origin
- **端点实现形态（Oracle P2-5）**：`/sso/*` 端点**非 RESTful**（302 redirect / HMAC 验签 / fragment 投递），**不适合 `[GenerateController]` SG1 控制器生成**——手写控制器或 minimal API（装配层/SSO 主包内，开发期裁定）
- **安全头**：`/sso/auth` 设 `Referrer-Policy: no-referrer`；access log 不记录 token（设计文档 §5.2）
- **限频**（设计文档 §8.11）：`/sso/issue`（per channel+IP）/ `/sso/auth` / `/sso/login`（per IP）/ profile（per app+uid）——装配层 RateLimiting 或 SSO 内窗口计数（开发期裁定）

### 5.8 联盟锚点数据模型（方案 A，Oracle P1-1/P1-2/P1-3）

> **列归属裁定（Oracle P1-3）**：`FederationAnchorOpenId`/`ChannelId`/`ExternalUserId` 列加在 **Authentication 主包实体**（`[Column]` + SG1 重新生成 .g.cs）——**不是 Abstractions DTO 加字段**（实体变更 ≠ DTO 变更）；SSO 消费面 DTO（Abstractions `SsoAccountDto`/`SsoChannelMapDto`）含对应字段，经 `ISsoAccountQueryService`/`ISsoChannelMapService` 消费。

**`AuthAccountEntity` 新增列**（Authentication 主包）：

| 列 | 类型 | 说明 |
|---|---|---|
| `FederationAnchorOpenId` | string?(64) | **联盟锚点 openid（一对一）**——联盟认证服务号 `snsapi_base` 取；跨商户稳定锚点；唯一索引（可空 NULL 放行） |

> ⚠️ **`UnionId` 列保留原语义**（微信开放平台 unionid，降级可选）——**不可重定义**（UserCenter 承接 ADR §五.4 微信绑定推导依赖：`WechatMpOpenId ?? WechatWebOpenId ?? UnionId` 任一非空 = 已绑定，P1-2）。

**`PlatformAccountMapEntity` 扩展**（一对多承载）：

| 新增列 | 类型 | 说明 |
|---|---|---|
| `ChannelId` | string?(64) | channel 实例 id（微信 = 公众号 id） |
| `ExternalUserId` | string?(128) | 渠道身份标识（商户 openid2） |

- **唯一约束（Oracle P1-3 明确）**：**保留既有 `UX_PlatformAccountMap(PlatformAccountId, BusinessAppId, BusinessLocalId)` 不变**（既有 V0.5.x 消费方依赖 `GetByPlatformAsync`/`GetByBusinessAsync`/`GetByUnionIdAsync`）；**新增 `UX_PlatformAccountMap_Channel(ChannelId, ExternalUserId)` 唯一索引**（SSO 联邦映射专用，ChannelId/ExternalUserId 可空——既有行 NULL 放行）

- **首次两步时序**（设计文档 §7）：① 认证中心经联盟服务号取联盟 openid → 写 `AuthAccount.FederationAnchorOpenId`（锚点）→ ② 转向商户取 openid2 → 写 `PlatformAccountMap`（`(channel_id, openid2) ↔ uid`）→ 后续任一 openid 直认（按锚点列或映射表反查）
- **降级路径**：联盟服务号不可行 → 手机号 OTP 绑定合并（设计文档 §7 通用锚点）

## 七、风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| Abstractions 拆包破坏既有消费方 | 高 | **实体保留主包不动**（Oracle P1-1）+ 新增契约非迁移既有接口（P1-2）+ 既有测试全量回归（S1/S12 为硬门槛） |
| ES256 手写签名实现缺陷 | 高 | 对齐 Authentication RS256 手写先例 + DevEcKeyCache（V0.5.3 模式，P2-3）+ 测试覆盖负路径（alg 强制/曲线强制/FixedTimeEquals/Base64Url 边界）+ JWKS 轮转（S11） |
| accesscode CAS 并发竞态 | 中 | 原子 UPDATE WHERE used=false + 败者重查（对齐 FileManagement v0.3.0 并发加固先例） |
| 联盟锚点表扩展迁移 | 中 | FederationAnchorOpenId/ChannelId/ExternalUserId 可空新列（增量迁移）+ 既有 UX 约束保留 + 新增 UX_PlatformAccountMap_Channel（S12 验证零回归） |
| 平台适配扩展与既有 Provider 重复建设 | 中 | §5.6 边界显式声明（ISsoChannel vs IAuthenticationProvider）+ 微信双轨边界文档化 |
| `/sso/login` state 跨实例一致性 | 中 | state 落库（SsoLoginStateEntity 或 accesscode 复用）——多实例 Worker 网关→轻量机场景需共享存储（开发期裁定 Redis/SQLite） |
| 第三形态契约实现归属矛盾 | 中 | S13 明确：SSO 经 Abstractions 契约；消费方未装配 Authentication 主包 → `ISsoAccountQueryService` 无实现 → 开发期裁定（SSO 降级/自持最小映射/要求装配）并在使用指南声明 |
| 部署侧 secrets 约定缺失（_TCloud） | 高（部署期） | 三项密钥（EC 私钥/HMAC/credential）存储载体开发期与 _TCloud 对齐定义（当前无既有约定，属 _TCloud 侧硬阻塞，登记） |
