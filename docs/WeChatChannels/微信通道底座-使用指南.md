# 微信通道底座扩展（WeChatChannels）使用指南

> **包**：`TKWF.Ext.WeChatChannels` V0.1.1 + `TKWF.Ext.WeChatChannels.Abstractions` V0.1.1（2026-11-05 首发——自 `WeChatOperations` V0.9.0 拆分下沉；V0.1.1 密钥键收口）
> **定位**：平台侧多通道接入管理（通道配置 CRUD / 凭证两源并存 / 通道注册源 / 能力派生）；**零运营依赖**（运营内容归 `WeChatOperations`）
> **技术规范**：`_Framework/WeChatChannels/README.md`

---

## 一、装配即模式（无 Mode 配置）

| 消费方 | 白名单 | 效果 |
|--------|--------|------|
| 平台侧 | `[TKWFEnabledExtension(typeof(WeChatChannelsExtensionInitializer<>))]` | 仅通道底座（轻量链） |
| 租户侧（运营） | **双白名单**：`WeChatChannelsExtensionInitializer<>` + `WeChatOperationsExtensionInitializer<>` | 通道底座 + 运营全套 |

> ⚠️ **白名单无传递语义**（ADR47）：租户侧漏声明 `WeChatChannels` → 通道门面/keyed 密钥/注册源未注册 → 首解析运行时失败（运营侧菜单/状态/网关全部不可用）。

## 二、安装

```xml
<PackageReference Include="TKWF.Ext.WeChatChannels" Version="0.1.1" />
<!-- 运营侧另引： -->
<PackageReference Include="TKWF.Ext.WeChatOperations" Version="0.9.0" />
```

`WeChatChannels.Abstractions` 由主包传递引用（运营扩展亦仅引契约包——L2）。

> ⚠️ **平台库装配前置（必做）**：消费方须先调用 `AddWeChatFederationChannels()`（Federation.WeChat 平台库注册 `WeChatApiClient`/`WeChatOauthChannel` wechat_oauth/`WeChatEventChannel` wechat_event 通道/`OptionsWeChatCredentialResolver` 缺省凭证实现）**再**白名单启用本扩展——不调用则 wechat_oauth/wechat_event 通道不注册、`IWeChatCredentialResolver` 缺省实现缺失、事件端点不可达（本扩展 `DbWeChatCredentialResolver` 依赖该契约两源并存）。

## 三、配置

```jsonc
{
  "TKWF": {
    "WeChatChannels": {
      "SecretEncryptionKeyPath": "<AES-GCM 密钥文件路径>",   // 生产必配（缺钥 fail-fast）
      "IsProduction": true                                  // 开发置 false（随机兜底密钥）
    }
  }
}
```

> **迁移提示（自 V0.9.0 拆分）**：原 `TKWF:WeChatOperations:SecretEncryptionKeyPath` / `IsProduction` 已迁至 `TKWF:WeChatChannels` 节。运营扩展网关（下游端点令牌加解密）消费**同一密钥键**——跨扩展同一信任域。

## 四、使用门面

```csharp
// 消费方（DomainUser 帧内）
var channels = user.Use<IChannelConfigService>();
var list = await channels.ListChannelsAsync(ct);                                  // 列表（DTO 不含凭证）
var one  = await channels.GetByChannelIdAsync("wechat-mp-main", ct);              // 按 channelId 查询
var id   = await channels.SaveChannelAsync(new SaveChannelRequest(               // 新建/更新（凭证明文可选）
    Id: null, ChannelId: "wechat-mp-main", AppId: "wx...", DisplayName: "主公众号",
    ChannelForm: "mp_service", Verification: "verified", AppSecret: "***", Token: "***", EncodingAesKey: "***"), ct);
await channels.DeleteChannelAsync(id, ct);
```

凭证语义：`AppSecret/Token/EncodingAesKey` 为**明文**入参（null = 保持库中既有密文不变）——门面 AES-GCM 加密落库；DTO 永不回显凭证（`HasCredentials` 仅布尔）。

## 五、REST 端点

| 方法 | 路径 | 权限 |
|------|------|------|
| GET | `/api/wechat-channels/channels` | `WeChatChannels.Query` |
| POST | `/api/wechat-channels/channels` | `WeChatChannels.Manage` |

> **非 Web 扩展形态**：控制器由消费方 SG2 按 ADR47 能力清单生成（对齐 Identity `/api/identity/*`、Notifications `/api/notifications/*` 先例）——消费方白名单声明后**自动挂载**，无需额外 `UseWebExtensions` 装配。RestBasePath 经 `TKWF:Api:RestBasePath` 配置（缺省 `/api`）。

## 六、权限键迁移（自 V0.9.0）

| 能力 | 旧键（≤V0.8.x） | 新键（V0.9.0+） |
|------|----------------|----------------|
| 通道查询/列表 | `WeChatOperations.Query` | `WeChatChannels.Query` |
| 通道保存/删除 | `WeChatOperations.Manage` | `WeChatChannels.Manage` |
| 运营内容（素材/菜单/规则/统计/日志/网关） | `WeChatOperations.*` | `WeChatOperations.*`（不变） |

消费方授权配置须同步迁移通道相关授予项。

> ⚠️ **权限定义声明（必做）**：消费方须实现 `IPermissionDefinitionContributor` 声明 `WeChatChannels.Query/Manage` 权限定义并注册（对齐 `Extension.Permissions.Consumer/ConsumerPermissionContributor.cs` 先例）——否则 `IPermissionDefinitionRepository` 无此权限 → `PermissionFilterAttribute` fail-closed 拒绝 → REST 端点永久 403（除非 Admin.All 兜底）。

## 七、凭证两源并存

| 源 | 说明 |
|----|------|
| ① DB（权威） | `TKWF_WeChatChannelConfig`——AES-GCM 密文；命中即解密返回 |
| ② Options（降级） | `TKWF:Federation:WeChat:Channels`——DB 未命中回退；非 AOP 帧（裸后台任务）同样降级 + Warning |

通道注册源 `Priority=100` 恒先于静态源；`Token/EncodingAESKey` 投影期解密进 `Channel.Extra`（事件验签需要），`AppSecret` 仅出站瞬时解密。

## 八、租户兼容说明（重要）

运营实体（素材/菜单/规则/日志等）实现 `IEntityTenant` 的**租户行级隔离不在本版本范围**——经设计原则评估否决后单列迭代：

- ADR34 写路径守卫（创建/更新/删除）对 `IEntityTenant` 实体**无条件激活**（无租户上下文即抛 `DomainException`），不受过滤器注册与否影响
- 事件入站链路（`/feberation/event/{channelId}`）与后台作业无租户上下文 → 若直接启用将导致事件回复/日志写入失败
- 实施前置：事件帧租户识别（channelId → TenantId 映射）+ 后台作业 `ExecuteInTenantAsync` + 消费方路由审查

通道配置表（`TKWF_WeChatChannelConfig`）为**平台级共享语义**（不实现 `IEntityTenant`——跨租户通道目录）。

## 九、常见问题

| 现象 | 原因 | 处置 |
|------|------|------|
| 启动/首解析抛"领域架构守卫" | 白名单漏声明 `WeChatChannels`（租户侧仅声明运营） | 双白名单补齐 |
| 通道端点 404 | 消费方未声明白名单（SG2 不生成控制器） | `[TKWFEnabledExtension]` 声明 |
| 生产启动失败（缺密钥） | `SecretEncryptionKeyPath` 未配或 `IsProduction=true` | 配密钥文件路径 |
| 事件验签恒失败 | 通道 Token/EncodingAESKey 密文无法解密（密钥不匹配） | 校验密钥文件一致性；注册源已 Warning 留痕 |
| 权限 403 | 消费方授权未迁移 `WeChatChannels.*` | 同步授权配置 |
