## ADR 三问必填（缺任一小节视为不完整，不予批准）

每个扩展 ADR 必须包含三个独立小节：
1. **目的与目标**——这个决策要达成什么？读者应在 3 句话内明白目标状态。
2. **问题**——为了解决什么问题？必须包含问题现象、触发场景、现有方案的不足。
3. **使用场景**——用于什么场景？列出具体场景，标注不适用边界。

详细规范见主框架 `_TKWF/docs/AC-Kit/guides/ADR编写指南.md`。
