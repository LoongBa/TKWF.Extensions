## 一、快速开始（或「安装」）

### 1. 引用扩展

```xml
<!-- 消费方 .csproj（NuGet 模式——生产推荐） -->

```

```xml
<!-- 源码模式（扩展仓库内联调） -->
<ProjectReference Include="..\_TKWF.Extensions\_Framework\{扩展名}\TKWF.Ext.{扩展名}.csproj" />
```

### 2. 启用（v4.9.85+ 必需）

> 📌 **公共接线机制**（发现≠启用 / 三钩子 / Web 钩子正交 / 启动期安全解析）见 [《扩展模块通用指南》](../扩展模块通用指南.md) §二/§四——以下仅列本扩展特有接线。

```csharp
// 消费方领域初始化器（DomainHostInitializerBase<TUserInfo> 子类）——白名单声明启用
using TKWF.Ext.{扩展名};

[TKWFEnabledExtension(typeof({扩展名}ExtensionInitializer<>))]
public class MyDomainInitializer : DomainHostInitializerBase<MyUserInfo>
{
    // ...
}
```

> 声明后自动注册：[特有服务列表——如 `ISettingStore` → `FreeSqlSettingStore`（Scoped）]。

> ⚠️ **Web 类扩展**（若有）——宿主面（中间件/端点）另需 `UseWebExtensions(e => e.Add<{扩展名}WebExtension>(...))` 装配（v4.10.45，见《扩展模块通用指南》§二第 3 步）。
